# Lesson 6.7 — 비용 추적 (간단 로그)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

호출 한 번이 *얼마였는지* 추적하는 게 좋아요. 처음에는 거의 안 비싸지만 *습관*을 들이면 나중에 큰 호출에서 도움이 돼요.

추적 방법:
1. **제공자 대시보드** — 가입한 페이지에서 *오늘/이번 달 사용량* 확인 가능
2. **응답 안의 토큰 수** — JSON 응답에 보통 `usage` 필드가 있어요 (입력 토큰 + 출력 토큰)
3. **간단 로그** — 호출할 때마다 *날짜·토큰 수*를 한 줄로 메모

처음 한 달은 그냥 *대시보드만 자주 보세요*. "오늘 0.05달러 썼네" 정도만 알아도 충분해요. 나중에 12강에서 *비용 최적화*를 더 자세히 다룹니다.

❓ {{name}}님 환경에서 비용을 *어떻게 추적할지* 떠오르세요? "대시보드 매일 보기" 정도도 OK.
