# Lesson 6.6 — 첫 호출 (curl 또는 SDK)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

API 호출은 *두 가지 방법* 중 하나로 해요.

1. **curl** — 명령어 한 줄로 호출. 가장 간단하지만 *결과가 텍스트로*만 나와요.
2. **SDK** — Python, Node 등 라이브러리. *프로그램 안에서* 호출. 비개발자에겐 약간 부담.

처음에는 **curl**로 시작하는 게 좋아요. 한 줄이면 *호출이 잘 되는지*만 빠르게 확인할 수 있어요. 가이드 실습에서 학습자 OS에 맞는 curl 명령어를 같이 한 번 실행해볼 거예요.

호출이 성공하면 *JSON 응답*이 옵니다. JSON은 *프로그램이 읽기 쉬운 형식*인데, 사람이 봐도 어떤 답인지 알 수 있어요.
