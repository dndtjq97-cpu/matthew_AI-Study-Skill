# Lesson 6.5 — 키를 어디에 보관할까요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

API 키는 *비밀번호*와 같아요. *코드에 직접* 박지 말고, *환경 변수*나 *비밀 파일*에 넣어두세요.

올바른 위치 (안전):
- ✅ `.env` 파일 (코드와 분리, `.gitignore`에 반드시 추가)
- ✅ OS의 환경 변수 (`export ANTHROPIC_API_KEY=sk-...`)
- ✅ 비밀 관리 도구 (1Password 등)

피해야 할 위치 (위험):
- ❌ 코드 안에 직접 (`api_key = "sk-..."`)
- ❌ 커밋된 파일에 (`config.json`을 git에 올리면 영영 노출)
- ❌ 메신저·이메일에 평문으로

가이드 실습에서 학습자 OS에 맞는 *가장 쉬운 안전한 방법*을 같이 봐드릴게요.

❓ {{name}}님 환경에 *비밀번호 같은 키를 보관하던 곳*이 있으세요? "1Password 써요" 같은 답이면 그대로 활용 가능해요.
