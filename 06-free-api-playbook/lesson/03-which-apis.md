# Lesson 6.3 — 어떤 API들이 있어요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

대표적인 LLM API 제공자 *3가지*만 알아두시면 충분해요.

1. **Anthropic (Claude)** — 신규 가입 시 일정 크레딧 (변동 가능). 카드 정보 필요할 수 있음.
2. **Google AI Studio (Gemini)** — 일일 RPM 한도까지 무료. 카드 정보 *없이* 시작 가능 (변동 가능).
3. **OpenRouter** — 여러 모델을 한 곳에서. *일부 무료 티어 모델* 사용 가능.

처음 시작하시는 분은 **Google AI Studio**가 가장 부담 적어요 (카드 등록 없이 무료 한도 시작). 다만 *최신 정책*은 가입 페이지에서 확인하세요.

🛠 **미션** — 위 3가지 중 *가장 끌리는 것 1개*를 골라주세요. "잘 모르겠어요"라고 답하시면 가이드 실습에서 가장 부담 적은 옵션으로 추천해드릴게요.

> 💾 골라주신 제공자는 자동 보관됩니다.
