# Lesson 6.4 — API 키 발급의 일반 흐름

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

API 키 발급은 *3단계*예요. 제공자마다 살짝 다르지만 흐름은 같아요.

1. **가입** — 이메일 + 비밀번호 (또는 Google 계정 등)
2. **카드 등록**(필요 시) — *무료 한도 안에서만 사용*하면 청구 안 됨. 다만 *실수로 한도 초과* 시 청구 가능.
3. **키 발급** — 대시보드에서 "Create API Key" 버튼 클릭 → *한 번만 보이는* 긴 문자열을 복사해서 안전한 곳에 저장.

⚠ 키는 *생성 시 한 번만* 보입니다. 못 봤거나 잃어버리면 *새로 발급* 받아야 해요. 그래서 가이드 실습에서 *어디에 저장할지*를 같이 결정할 거예요.

🛠 **미션** — 학습자가 *현재 확인한 무료 한도*가 있으면 적어주세요. (예: "Google AI Studio 분당 60회") 가입 페이지에서 본 그대로면 됩니다.

> 💾 적어주신 한도는 자동 보관돼요. 잊어버려도 다시 알려드릴 수 있어요.
