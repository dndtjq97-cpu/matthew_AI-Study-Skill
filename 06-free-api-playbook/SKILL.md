# Lesson 06 — 무료 API 플레이북 💰

> 학습자가 끝나면 무료/저비용 LLM API 1개를 본인 환경에 연결해 *첫 호출*까지 시연한다.

이 스킬은 *대화형 강의*입니다. 한 청크씩 따라오며 학습자가 *어떤 API를 고를지* 직접 결정하고, 키 발급 → 안전 보관 → 호출까지 옆에서 가이드합니다. **이 강의는 비용 발생 가능성이 크므로 시작 시점부터 자유 스킵을 강조**합니다.

2. `progress["06-free-api-playbook"].status` 분기.
3. **첫 청크 출력 전 강의 자체 스킵 옵션 제시** — `_shared/guided-practice-protocol.md`의 비용 투명성 섹션 참조.
   ```

   자체를 스킵하셔도 돼요. 13강에서 무료 로컬 LLM 옵션도 다뤄요.
     (1) 그래도 진행 (무료 옵션 우선)
     (2) 강의 스킵 → 다음 강의로
   ```

5. 이론 진입. 헤더 `📘 [Lesson 6 · 청크 X/Y]`.

7. 실습 종료 → 진도 갱신 + 다음 강의(7강).

## 3. 이론 lesson 흐름

청크 8개. *현재 무료 정책*은 자주 바뀌므로 학습자에게 직접 확인을 요청.

### 6강에서 *왜* 한 청크씩 가는가
API 발급은 *비용 결정*이라 학습자가 매 단계에서 *멈출 수 있어야* 합니다. 한 번에 다 보여주면 부담을 못 느끼고 진행하다가 나중에 청구서를 보고 놀라요. 한 청크씩 *비용 확인 → 다음*으로 가야 학습자가 안심하고 통제하며 진행할 수 있습니다.

## 4. 가이드 실습 — 3개 옵션 (`practice/options/`)

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 진짜로 키를 발급해볼 시간이에요.

📝 고른 제공자: <draft.chosen_provider>
📝 확인한 무료 한도: <draft.free_tier_limits_noted>

다시 한번 알려드려요 — 무료 한도는 자주 바뀌니 가입 페이지에서 *현재
정책*을 직접 확인해주세요. 진행하시겠어요?
```

### 4-1. 옵션 제시 (3개)

```
어떤 제공자로 진행하시겠어요?

  (1) Anthropic Claude — 신규 가입 시 일정 크레딧 (변동 가능)
  (2) Google AI Studio (Gemini) — 일정 RPM·일일 한도 무료 (변동 가능)
  (3) OpenRouter — 일부 모델 무료 티어 (변동 가능)

번호로 답해주세요. 비용이 부담되시면 "스킵"이라고 답하셔도 돼요.
```

각 옵션 → `practice/options/anthropic.md` / `google-ai-studio.md` / `openrouter.md` 로드.

### 4-2. 가이드 실습 7단계

`_shared/guided-practice-protocol.md` 그대로:
1. 옵션 선택
2. 사전 점검 — 카드 정보 필요 여부, 학습자 부담 재확인
3. **💰 비용 안내 의무** — 표준 안내문 + (1) 진행 / (2) 스킵 / (3) 무료 옵션 더 알아보기 분기
4. 키 발급 단계 안내 (학습자가 직접 가입 페이지로 이동)
5. 키 안전 보관 — 환경 변수, `.env`, 절대 코드에 직접 박지 않기
6. 첫 호출 (학습자 OS 맞춤)
7. 검증 + 마무리

### 4-3. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 키가 *안전한 위치*에 보관됨 | ✅ |
| 첫 호출이 *성공* (응답 수신) | ✅ |
| 학습자가 *비용 추적 방법*을 안다 (대시보드 위치 등) | ✅ |

3개 중 2개 이상 ✅.

### 4-4. 트러블슈팅
401/403 에러 → 키 잘못 복사. 429 → 한도 초과. 결제 정보 누락 → 가입 페이지 재확인.

## 8. 강의 작성자 메타

- **트랙**: 기초 6강
- **선행**: 1~5강 (권장)
- **분량**: 약 30분
- **외부 자료 의존**: 학습자가 가입할 외부 LLM 서비스
- **💰 비용**: **큼** (변동 가능, 강의·실습 모두 자유 스킵)
- **학습 목표**:
  - 무료 LLM API 1개를 본인 환경에 연결
  - 키를 *안전하게 보관*하는 방법을 안다
  - 비용 추적 방법을 안다
