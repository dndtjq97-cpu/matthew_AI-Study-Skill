# Practice — 가이드 실습 (6강 무료 API) 💰

> `_shared/guided-practice-protocol.md`의 7단계 + **비용 안내 의무** 적용.

## 0. 진입 직전 — 강의 자체 스킵 옵션 재확인

```
이 실습은 외부 API 키 발급이 필요해요. 다시 한번 확인:

  (1) 그래도 진행 (무료 옵션 우선)
  (2) 강의 스킵 → 다음 강의로 (⚠ 실습 미이행)
  (3) 무료 옵션이 어떤 게 있는지 먼저 알려주세요
```

(3) 선택 시 무료 옵션 안내 후 다시 (1)/(2) 분기.

## 1. 옵션 제시 (3개)

```
어떤 제공자로 진행하시겠어요?

  (1) Anthropic Claude — 신규 가입 시 일정 크레딧 (변동 가능)
  (2) Google AI Studio (Gemini) — 일일 한도 무료 (변동 가능, 카드 안 받기도)
  (3) OpenRouter — 일부 무료 티어 모델

번호로 답해주세요. 비용 부담되시면 "스킵"이라고 답하셔도 OK.
```

각 옵션 → `practice/options/anthropic.md` / `google-ai-studio.md` / `openrouter.md` 로드.

## 2. 공통 흐름 (옵션 가이드는 옵션 파일에)

각 옵션 파일이 다음 7단계를 담음:
1. 옵션 선택 (위)
2. 사전 점검 — 가입에 필요한 것 (이메일, 카드 여부)
3. **💰 비용 안내** (다시) + 자유 스킵 옵션 재확인
4. 가입 + 키 발급 단계 안내 (학습자가 가입 페이지로)
5. 키 안전 보관 (학습자 OS 맞춤 환경 변수 설정)
6. 첫 호출 (curl 명령 학습자 OS 맞춤)
7. 검증 + 마무리

## 3. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 키가 *안전한 위치*에 보관 (코드에 직접 X) | ✅ |
| 첫 호출 *성공* (응답 수신) | ✅ |
| 비용 추적 방법 *알고 있음* (대시보드 위치) | ✅ |

3개 중 *2개 이상* 통과 시 ✅.

## 4. 트러블슈팅

- **401/403** — 키 잘못 복사 또는 만료. 키 재확인.
- **429** — 한도 초과. 잠시 대기 또는 다른 모델 시도.
- **결제 정보 누락** — 가입 페이지에서 카드 등록 또는 무료 옵션 전환.

## 5. 마무리

### 진도 갱신
- 통과: `status = "completed"`, `practice_status = "done"`
- 강의 자체 스킵: `status = "skipped"`, `practice_status = "not_done"`
- 실습 스킵: `status = "completed"`, `practice_status = "not_done"`

### 비용 추적 안내 (마지막 한 번 더)

```
{{name}}님이 발급받은 키로 *언제든 사용량 확인*이 가능해요.
대시보드 URL은 위에서 안내드린 페이지에서 보실 수 있습니다.
한 달 한 번 정도는 확인하시는 걸 추천드려요.
```
