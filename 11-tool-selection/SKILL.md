# Lesson 11 — 도구 선택 사고법 (심화 트랙 4)

> 학습자가 끝나면 4가지 기준(정확성/속도/비용/위험)으로 본인 시나리오에 맞는 도구를 *근거 있게* 선택한다.

## 3. 이론 lesson 흐름
청크 8개.

### 11강에서 *왜* 한 청크씩 가는가
도구 선택은 *근거 사고*가 필요합니다. 한 번에 비교표를 다 보여주면 "결과만 보고" 외워버려요. 한 청크씩 *기준 → 적용 → 다음*으로 가야 본인이 새 시나리오를 만났을 때도 같은 사고를 할 수 있습니다.

---

## 4. 가이드 실습 — 옵션 2개 인라인

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 본인 시나리오에 적용해볼 시간이에요.

📝 시나리오: <draft.scenario>
📝 후보들: <draft.candidates>
📝 고른 도구: <draft.chosen_tool>
📝 이유: <draft.reason>
```

### 4-1. 옵션 제시

```
어떤 시나리오로 결정해볼까요?

  (1) {{name}}님 본인 시나리오 (이론에서 적어주신 것)
  (2) 가상 시나리오 (예: "긴 PDF 요약하기")

번호로 답해주세요.
```

### 4-2. 가이드 흐름
선택지(명령어/API/MCP/서브에이전트/직접 처리) 중에서 *4기준 매핑* → 도구 선택 → 시연(가능하면).

### 4-3. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 후보 *2개 이상* 비교 | ✅ |
| 4기준 중 *2개 이상*을 명시적으로 적용 | ✅ |
| 선택 *이유*가 한 줄로 명확 | ✅ |

3개 중 2개 이상 ✅.
