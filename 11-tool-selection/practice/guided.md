# Practice — 가이드 실습 (11강 도구 선택)

> `_shared/guided-practice-protocol.md`의 7단계를 따릅니다.

## 0. 진입 직전 (draft 정리)

이론에서 적은 `scenario` / `candidates` / `chosen_tool` / `reason`을 정리해 보여줌.

## 1. 옵션 제시 (2개 인라인)

```
어떤 시나리오로 결정해볼까요?

  (1) {{name}}님 본인 시나리오 (이론에서 적어주신 것)
  (2) 가상 시나리오 — 예: "긴 PDF 매주 요약하기"

번호로 답해주세요.
```

## 2. 옵션 ① — 본인 시나리오

### 2-1. 4기준 매트릭스

학습자에게 보여주기:

```
{{name}}님 시나리오: <draft.scenario>

후보 도구: <draft.candidates>

각 후보를 4기준으로 점검해볼게요.

| 후보 | 정확성 | 속도 | 비용 | 위험 |
|---|---|---|---|---|
| 후보 A | ? | ? | ? | ? |
| 후보 B | ? | ? | ? | ? |
| ... | | | | |

각 칸에 ↑ ↔ ↓ 중 하나로 적어주세요.
```

### 2-2. 결정 + 이유

채워진 매트릭스를 보고 *최종 도구* 결정. 이유는 *어떤 기준이 결정적*이었는지 한 줄로.

### 2-3. 가능하면 시연
선택한 도구가 *간단한 작업*이면 한 번 실행해보기 (예: "스킬로 만들면 1분 내 시연 가능").

## 3. 옵션 ② — 가상 시나리오

강의 제공 시나리오로 *동일한 4기준 매트릭스* 작성. 학습자가 *판단 근거*를 명시적으로 표현.

## 4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 후보 *2개 이상* 비교 | ✅ |
| 4기준 중 *2개 이상* 명시적 적용 | ✅ |
| 선택 *이유*가 한 줄로 명확 | ✅ |

3개 중 *2개 이상* 통과 시 ✅.

## 5. 트러블슈팅

- 후보가 한 가지밖에 안 떠오름 → *반대 극단*으로 1개 추가 (예: "그냥 직접 하기")
- 모든 기준이 비슷함 → *위험* 기준이 결정적인 경우 많음
