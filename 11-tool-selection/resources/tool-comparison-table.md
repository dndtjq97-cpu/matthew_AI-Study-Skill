# 도구 비교표 (4기준)

> 강의에서 다룬 도구들을 *4기준*으로 한눈에 비교.

## 비교표

| 도구 | 정확성 | 속도 | 비용 | 위험 | 적합한 작업 |
|---|---|---|---|---|---|
| **명령어/스크립트** | ↑↑ | ↑↑ | 무료 | ↓ | 결정론적, 반복적 |
| **직접 API 호출** | ↑ | ↑ | 호출당 | ↔ | 자동화, 통합 |
| **MCP (3강)** | ↔↑ | ↔ | 보통 무료 | ↔ | 외부 도구 연결 |
| **서브에이전트 (8강)** | ↔ | ↓ | LLM | ↔ | 컨텍스트 보호 |
| **hook (9강)** | ↑ | ↑↑ | 무료 | ↔ | 자동 트리거 |
| **n8n 워크플로우 (10강)** | ↑ | ↔ | 호출당 | ↓ | 시각적 자동화 |
| **그냥 에이전트** | ↔ | ↑ | LLM | ↓ | 1회성 작업 |
| **도구 안 쓰기** | ↑↑ | ↑ | 무료 | ↓ | 드물게, 단순 |

↑ = 좋음 / ↔ = 보통 / ↓ = 낮음/문제

## 선택 기준 다이얼

본인 작업의 *결정적 기준*을 골라 매핑:

| 결정적 기준 | 추천 도구 |
|---|---|
| **정확성**이 가장 중요 | 명령어, hook |
| **속도**가 가장 중요 | 명령어, hook, 캐싱 활용 |
| **비용**이 가장 중요 | 명령어, MCP, 도구 안 쓰기 |
| **위험 통제**가 가장 중요 | n8n 워크플로우 (시각화), 명령어 |

## 도구 안 쓰기를 고려할 때

- 한 달에 1번 이하인 작업
- 매번 입력이 *완전히 다른* 작업
- *5분 절약하려고 1시간 자동화*는 손해
- 사람이 *판단*해야 하는 위험한 결정

자동화 비용이 절약 시간을 *넘어서면* 도구 안 쓰는 게 합리적입니다.

## 도구 조합 (체이닝) 패턴

| 패턴 | 예시 |
|---|---|
| MCP + 서브에이전트 | MCP로 데이터 → 서브가 처리 |
| hook + 스크립트 | hook 발사 → 스크립트 실행 |
| n8n + LLM 노드 | 워크플로우 안에 LLM (10강) |
| 명령어 + API | 스크립트가 API 호출 |

처음에는 *2개 조합*부터.
