# Lesson 11.2 — 도구 선택의 4가지 기준

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

도구를 고를 때 *4가지 기준*만 점검하면 거의 안 헤매요.

1. **정확성** — 결과의 *일관성*. 매번 같은 입력에 같은 결과가 필요한가?
2. **속도** — *얼마나 빨리* 끝나야 하는가?
3. **비용** — *호출당 비용*이 적정한가? (LLM 호출, API 비용 등)
4. **위험** — *실수했을 때* 영향 범위. (자동 삭제 vs 결과 보고)

작업이 *정확성·일관성*이 중요하면 → 코드/스크립트
*속도*가 중요하면 → 빠른 도구
*비용*이 중요하면 → 무료 옵션 또는 단순 도구
*위험이 큰* 작업은 → 사람 검토 단계 추가

❓ 위 4기준 중 본인 작업에서 가장 *결정적*인 게 무엇 같으세요?
