# Lesson 11.5 — 도구 조합 (체이닝)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

한 도구로 다 안 되면 *여러 도구를 이어서* 사용할 수 있어요. 이걸 **체이닝**이라고 해요.

흔한 체이닝 패턴:
- **MCP + 서브에이전트**: MCP로 데이터 가져오고 → 서브에이전트가 처리
- **hook + 스크립트**: hook이 트리거 → 스크립트가 작업
- **n8n + LLM**: 워크플로우 안에 LLM 노드 끼워넣기 (10강에서 봄)
- **명령어 + API**: 스크립트가 API 호출 → 결과 정리

체이닝은 *각 도구의 강점*을 합쳐주는데, *복잡도가 올라가요*. 처음엔 *2개 조합*부터 시작하시는 걸 추천. 3개 이상 체인은 익숙해진 뒤에.

🛠 **미션** — 본인 시나리오에 *2개 도구 조합*이 필요할 것 같으면 어떤 조합이 떠오르세요? "잘 모르겠어요"도 OK.
