## Chunk 1

지금까지 강의에서 *명령어, API, MCP, 서브에이전트, hook, 워크플로우*까지 다양한 도구를 만났어요. 이제 *어떤 작업에 어떤 도구를 쓸지*가 고민될 수 있어요.

같은 작업도 *여러 도구로* 가능해요. 예를 들어 "회의록 요약"은:
- 그냥 에이전트한테 부탁 (가장 단순)
- API 호출로 자동화 (코드 필요)
- MCP로 캘린더 연결 후 자동 (3강)
- 서브에이전트로 분리 (8강)
- n8n 워크플로우로 (10강)
