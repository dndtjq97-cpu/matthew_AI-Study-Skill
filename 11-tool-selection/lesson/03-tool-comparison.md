# Lesson 11.3 — 명령어 vs API vs MCP vs 서브에이전트 비교

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

지금까지 다룬 도구를 *4기준*으로 비교해볼게요.

| 도구 | 정확성 | 속도 | 비용 | 위험 |
|---|---|---|---|---|
| 명령어/스크립트 | 매우 높음 | 매우 빠름 | 무료 | 낮음 |
| 직접 API 호출 | 높음 | 빠름 | 호출 비용 | 중간 |
| MCP | 중간~높음 | 중간 | 보통 무료 | 중간 |
| 서브에이전트 | 중간 | 느림 | LLM 비용 | 중간 |
| 워크플로우(n8n) | 높음 | 중간 | 호출 비용 | 낮음 |

대략적인 패턴이에요. 정밀한 작업은 *명령어*, 유연성이 필요하면 *서브에이전트*, 가시화가 필요하면 *워크플로우*.
