# Menu Template — 메뉴·진도 출력 표준

학습자가 패키지에 진입했을 때 보이는 *메뉴 출력 형식*과 *분기 흐름*을 정의합니다.

---

## 1. 첫 진입 시 (프로필 없음)

```
안녕하세요! AI 에이전트 강의 패키지에 오신 것을 환영해요.

먼저 몇 가지만 여쭤볼게요. (한 번만 물어보고, 다음부턴 안 물어봐요)

1) 이름이나 닉네임을 알려주세요.
   → _______

2) 어떤 분야에서 에이전트를 활용해보고 싶으세요?
   (예: 1인 콘텐츠 운영, 회의록 자동화, 학습 도우미, 자유 입력 등)
   → _______

3) 본인의 기술 수준을 골라주세요.
   (1) 비개발자 — 터미널이 처음이에요
   (2) 개발자 — 코드/CLI 익숙해요
   (3) 어중간 — 따라는 가는 정도예요
   → _______
```

답변을 받으면 OS·셸은 자동 감지 후 `_shared/learner-profile.json`을 생성하고, 곧장 *상위 메뉴*를 띄웁니다 (다음 §2 참조).

---

## 2. 상위 메뉴 (모든 진입의 시작점)

프로필이 *방금 생성됐든* *이미 있든* 같은 상위 메뉴로 시작합니다.

### 2-1. 처음 진입 (프로필 막 생성)

```
좋아요, {{name}}님! 무엇을 도와드릴까요?

  (1) 강의 듣기 — 0강 + 1~15강 + 부록
  (2) AI 공부할 때 참고하면 좋은 유튜브 추천

번호로 답해주세요.
```

학습자 응답:
- **(1) 강의 듣기** → 0강 권장 분기 출력 (§2-3) → 0강 또는 강의 메뉴
- **(2) 추천 자료** → `RESOURCES.md` 출력 + 학습자 추가 질문 처리 → 끝나면 다시 상위 메뉴

### 2-2. 두 번째 이후 진입

```
👋 다시 오셨네요, {{name}}님!

무엇을 도와드릴까요?

  (1) 강의 듣기 — 진도 이어서 또는 새 강의
  (2) AI 공부할 때 참고하면 좋은 유튜브 추천

번호로 답해주세요.
```

학습자 응답:
- **(1)** → 진도 메뉴 출력 (§3-1)
- **(2)** → `RESOURCES.md` 출력 → 끝나면 다시 상위 메뉴

### 2-3. (1) 강의 듣기 진입 시 — 0강 권장 분기

처음 강의 듣기 진입 시 (`progress["00-prerequisites"].status == "not_started"`이면) 0강 권장:

```
본 강의 1~15강에 들어가기 전에 *알아두면 좋은 용어*와 *미리 가입할 곳*을
10분 안에 훑는 0강이 있어요. 비개발자라면 듣고 가시는 걸 추천드려요.

  (1) 0강 시작 (권장)
  (2) 익숙해서 건너뛰기 (강의 메뉴로 바로)
```

학습자가 (1) → 0강 진입. (2) → 강의 메뉴 (§3-1).

이미 0강을 듣거나 스킵한 분에겐 이 분기를 *생략*하고 곧장 §3-1로.

## 3. 강의 메뉴 (상위 메뉴 (1) 선택 시)

### 3-1. 표준 메뉴

```
👋 다시 오셨네요, {{name}}님!

지금까지의 진도를 보여드릴게요.

📖 [강의 시작 전]
  [0강] prerequisites          ✅ 수강완료 (또는 ⏭ 스킵 또는 🔒 미수강)

🎓 [기초 트랙]
  [1강] agents-md             ✅ 수강완료 (2026-05-02)
  [2강] skills                ✅ 수강완료 (2026-05-02)
  [3강] mcp                   ⏳ 진행중 (청크 4/8)        ← 이어서 듣기 추천
  [4강] prompt-engineering    🔒 미수강
  [5강] context-management    🔒 미수강
  [6강] free-api-playbook     🔒 미수강
  [7강] debugging             🔒 미수강

🚀 [심화 트랙]                  (기초 완료 후 잠금 해제)
  [8강] subagents             🔒
  [9강] hooks                 🔒
  [10강] work-decomposition   🔒
  [11강] tool-selection       🔒
  [12강] cost-mgmt            🔒
  [13강] local-cloud-privacy  🔒
  [14강] multi-agent-design   🔒

🎯 [캡스톤]                     (심화 완료 후 잠금 해제)
  [15강] build-your-own-harness 🔒

어떻게 진행하실까요?
  - 번호 또는 이름 입력 (예: "3" 또는 "mcp 이어서")
  - 처음부터 다시: "1강부터"
  - 진도 확인만: "진도"
  - 패키지 종료: "종료"
```

---

## 3. 진도 상태 아이콘

| 아이콘 | progress 상태 | 의미 |
|---|---|---|
| ✅ | `status: completed` & `practice_status: done` | 수강완료 |
| ⚠ | `status: completed` & `practice_status: not_done` | 수강했지만 실습 미이행 |
| ⏳ | `status: in_progress` | 진행중 (현재 청크 표시) |
| ⏭ | `status: skipped` | 스킵됨 (수강완료 아님) |
| 🔒 | `status: not_started` | 미수강 |

---

## 4. 권장 순서 + 우회 정책 (Q10 B)

### 진행 중인 강의 강조
`progress` 안에 `in_progress` 상태인 스킬이 있으면, 메뉴 출력 시 그 강의 옆에 `← 이어서 듣기 추천` 표시.

### 우회 시도 시 한 번 더 확인
학습자가 권장 다음 강의(예: 4강)를 건너뛰고 더 뒤(예: 7강)를 선택하면, **한 번만** 다음 안내를 띄웁니다:

```
[7강] debugging은 [3강] mcp, [4강] prompt-engineering 내용을 일부 사용해요.
앞 강의를 안 보셨다면 용어가 낯설 수 있어요.

그래도 [7강]을 먼저 보시겠어요?
  - 네, [7강] 시작
  - 아니요, 권장 순서로 [3강] 이어서
```

학습자가 "네"라고 답하면 그대로 진입. 다음에 또 우회해도 같은 안내를 다시 띄우지 않음(한 세션 내).

### 잠금이 풀리는 시점
- **기초 트랙**: 처음부터 모든 7개 강의가 메뉴에 노출되어 있고 자유 선택 가능. 위 우회 안내만 적용.
- **심화 트랙**: 기초 7개 모두 `status: completed` 또는 `skipped` 일 때 노출. 그 전까지 메뉴에 🔒로만 표시.
- **캡스톤(15강)**: 심화 7개 모두 `completed` 또는 `skipped` 일 때 노출.

## 5. 트랙 전환 분기 — 기초 종료 시점

기초 트랙 마지막 강의(7강) 마무리 직후, 학습자에게 다음을 묻습니다:

```
🎉 기초 트랙 완주 축하드려요, {{name}}님!

여기까지 따라오셨다면 이미 본인만의 작은 하네스를 운영할 수 있는 기초가 잡힌 거예요.
이제 어떻게 하시겠어요?

  (1) 심화 트랙 바로 시작 — subagents, hooks 등 본격 자동화
  (2) 일단 기초만 — 며칠 써보고 다시 결정할게요
  (3) 여기서 마무리 — 강의 종료

어떤 길로 가실까요?
```

응답에 따라 `track_decisions.advanced_decision`을 갱신:
- (1) → `"yes"` + `track = "advanced"` + 8강 진입
- (2) → `"pending"` + 메뉴로 복귀
- (3) → `"no"` + 종료 인사

`pending` 상태에서 다음 진입 시 메뉴 위에 짧은 안내:

```
🔔 심화 트랙 진입 결정이 보류 상태예요.
   메뉴에서 "심화 시작" 또는 "심화 안 함"을 입력하시면 결정할 수 있어요.
```

---

## 6. 명령어 단축 표

| 학습자 입력 | 동작 |
|---|---|
| 숫자(예: `3`) | 해당 번호 강의 진입 |
| 강의명(예: `mcp`) | 해당 강의 진입 |
| `이어서` 또는 `다음` | `in_progress` 강의 이어서 진입 |
| `1강부터` | 1강 처음부터 (진도 리셋 옵션 묻기) |
| `진도` | 메뉴 다시 출력 |
| `심화 시작` | `track = advanced` + 8강 진입 |
| `심화 안 함` | `advanced_decision = no` |
| `리셋` | 진도 초기화 (확인 받고 진행) |
| `넘어가` | 현재 청크 또는 lesson 스킵 (teaching-protocol.md 참조) |
| `종료` | 종료 인사 후 세션 마무리 |

---

## 7. 메뉴는 *어디서* 호출되는가

루트 `README.md`의 진입 스킬이 메뉴를 출력합니다. 각 lesson 종료 시(또는 학습자가 `진도` 명령 시)에도 이 템플릿을 따릅니다.

> 메뉴 자체는 별도 SKILL.md가 아닙니다. 루트 README + 각 SKILL.md가 이 템플릿을 따라 *직접 출력*합니다.
