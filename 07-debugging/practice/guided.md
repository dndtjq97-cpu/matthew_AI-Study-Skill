# Practice — 가이드 실습 (7강 디버깅)

> `_shared/guided-practice-protocol.md`의 7단계 + 🎓 **기초 트랙 완주 분기** 추가.

## 0. 진입 직전 (draft 정리)

이론에서 적은 `recent_issue` / `diagnosis_checklist_results`를 정리해 보여줌.

## 1. 옵션 제시 (2개 인라인)

```
어떤 사례로 풀어볼까요?

  (1) {{name}}님 본인 사례 (이론에서 적어주신 것)
  (2) 강의가 제공하는 가상 사례

번호로 답해주세요.
```

## 2. 옵션 ① — 본인 사례

### 2-1. 사례 재확인
- 학습자에게 *현재 상황* 한 번 더 요약 받기 (모호한 부분 있으면 보충 질문)
- 에러 메시지가 있으면 *그대로* 공유

### 2-2. 진단 적용
이론에서 받은 10개 체크리스트 중 *적합한 5개*를 함께 적용:
- 부탁이 명확한가?
- 입력이 다 들어왔나?
- 도구·MCP가 살아 있나?
- 최근 무엇이 바뀌었나?
- 같은 부탁이 다른 환경에서는?

### 2-3. 가설 → 시도 → 결과
- 가장 의심되는 1가지 가설로 *짧은 시도*
- 결과를 학습자가 붙여넣음
- 통과 시 → 다음 단계 / 실패 시 → 다른 가설

### 2-4. 수정 적용
가설이 맞으면 그 부분을 *고정*. `draft.fix_applied` 갱신.

## 3. 옵션 ② — 가상 사례

강의 제공 시나리오 (예: "에이전트가 같은 답만 반복") → 함께 진단 → 가설 → 결론.

## 4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 진단 체크리스트 *3개 이상* 적용 | ✅ |
| 근본 원인 *가설 1개 이상* 도출 | ✅ |
| `fix_applied`가 *실행 가능* | ✅ |

3개 중 2개 이상 ✅.

## 5. 트러블슈팅

- 가설이 다 틀림 → *재현이 안 되는 환경 의존* 가능. 다음 발생 때 더 자세히 기록.
- 학습자가 *어디부터* 봐야 할지 막힘 → 1번 체크리스트(부탁 명확성)부터 시작 안내.

## 6. 마무리 + 🎓 기초 트랙 완주 분기

### 진도 갱신
- 통과: `status = "completed"`, `practice_status = "done"`
- 포기: `practice_status = "not_done"`

### 🎓 기초 트랙 완주 분기 (학습자에게 출력)

```
🎉 기초 트랙 완주 축하드려요, {{name}}님!

여기까지 따라오셨다면 이미 본인만의 작은 하네스를 운영할 수 있는 기초가
잡힌 거예요. 이제 어떻게 하시겠어요?

  (1) 심화 트랙 바로 시작 — subagents, hooks 등 본격 자동화
  (2) 일단 기초만 — 며칠 써보고 다시 결정할게요
  (3) 여기서 마무리 — 강의 종료
```

응답에 따라 `track_decisions.advanced_decision`을 갱신:
- (1) → `"yes"` + `track = "advanced"` + 8강 진입
- (2) → `"pending"` + 메뉴 복귀
- (3) → `"no"` + 종료 인사
