# Lesson 7.2 — 5가지 흔한 실패 패턴

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

에이전트가 막히는 *5가지 흔한 패턴*이에요.

1. **모호한 부탁** — 4강에서 봤듯, 명확함 부족
2. **컨텍스트 부족** — 5강에서 봤듯, 필요한 정보가 안 들어옴
3. **도구·권한 문제** — MCP가 안 떠 있거나 키가 만료
4. **외부 상황** — 네트워크 끊김, 외부 API 응답 없음
5. **모델 한계** — 특정 작업이 *원래 어려운* (예: 정확한 산술)

대부분은 1~3번 중 하나예요. 4·5번은 드뭅니다. 그래서 *디버깅 시작점*은 항상 1~3번부터예요.
