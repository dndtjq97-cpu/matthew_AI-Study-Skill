# Lesson 7.3 — 진단 체크리스트 (10개 질문)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

에이전트가 막혔을 때 *순서대로 던져볼 10개 질문*이에요.

1. 부탁이 *명확한가*? (5요소 점검)
2. 필요한 *입력이 다 들어왔나*?
3. 컨텍스트가 너무 *길어서 잘렸나*?
4. 사용하는 도구·MCP가 *살아 있나*?
5. API 키·인증이 *유효한가*?
6. 네트워크가 *연결되어 있나*?
7. *같은 부탁*이 다른 환경에서는 되는가?
8. 에러 메시지를 *잘 읽었는가*?
9. *최근 무엇이 바뀌었나*?
10. 이 작업이 *원래 어려운* 종류인가?

🛠 **미션** — 1번 청크에서 떠올리신 *최근 막힌 사례*에 위 10개 질문을 *5개 정도만* 적용해보세요. 어떤 질문이 *가장 도움이 됐는지* 적어주세요.
