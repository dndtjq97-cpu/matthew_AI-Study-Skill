# Lesson 3.3 — MCP는 어떻게 동작해요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

MCP는 *서버*와 *클라이언트* 두 부분으로 나뉘어요.

- **MCP 서버** — 외부 도구(파일 시스템, 깃허브, 캘린더 등) 쪽에서 도는 작은 프로그램. 에이전트가 *어떤 작업이 가능한지* 알려주는 역할.
- **MCP 클라이언트** — {{name}}님이 사용하시는 에이전트 안에 내장. 서버에 *요청을 보내고 결과를 받아옴*.

학습자가 "이 폴더 봐줘"라고 부탁하면 → 클라이언트가 → 서버에게 → 폴더 정보 요청 → 서버가 응답 → 에이전트가 받아서 답변. 이 흐름이에요.

❓ 서버·클라이언트 구조가 머릿속에 그려지세요? 헷갈리시면 *어느 부분*이 어려운지 알려주세요.
