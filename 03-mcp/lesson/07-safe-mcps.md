# Lesson 3.7 — 안전한 MCP / 주의해야 할 MCP

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

MCP 서버는 *외부 코드*를 본인 컴퓨터에서 돌리는 거예요. 그래서 *어디서 받았는지*가 중요해요.

✅ **안전한 출처:**
- 공식 MCP 저장소 (`@modelcontextprotocol/...`)
- 잘 알려진 회사·프로젝트가 만든 MCP

⚠ **주의가 필요한 MCP:**
- 출처가 불분명한 npm 패키지
- 권한을 *너무 많이* 요구하는 MCP (예: 전체 디스크 쓰기 권한)
- 별이 거의 없는 신생 패키지

특히 *filesystem* 같이 파일 시스템에 접근하는 MCP는 *어떤 폴더만* 보게 할지 *반드시* 제한하세요. 가이드 실습에서 안전한 폴더 지정 방법을 같이 봐드릴게요.

❓ 출처·권한 점검에 대해 이해되셨어요? 더 알고 싶은 부분 있으시면 알려주세요.
