> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

MCP는 *공식 목록*과 *커뮤니티 제작*이 있어요. 처음 시작할 때는 *공식 목록*에서 고르는 게 안전합니다.

자주 쓰이는 무료 MCP:
- **filesystem MCP** — 폴더 안 파일 읽기·쓰기
- **memory MCP** — 대화 기억을 장기 보관
- **github MCP** — GitHub 이슈·PR 조회
- **sqlite MCP** — 작은 DB 조회
- **fetch MCP** — 웹 페이지 가져오기
