# Lesson 3.1 — MCP가 뭐예요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

MCP는 **Model Context Protocol**의 줄임말이에요. *에이전트와 외부 도구를 잇는 표준 다리*라고 생각하시면 됩니다.

지금까지 에이전트는 *대화 안*의 정보만 알았어요. MCP를 연결하면 폴더 안 파일을 읽거나, 캘린더 일정을 가져오거나, 외부 데이터베이스를 조회할 수 있어요.
