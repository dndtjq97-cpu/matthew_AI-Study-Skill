# Lesson 3.6 — 설치 흐름 미리 보기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

MCP 설치는 일반적으로 *3단계*예요. 자세한 명령어는 가이드 실습에서 학습자 OS에 맞춰 알려드릴 거예요. 지금은 *흐름만* 미리 봐주세요.

1. **MCP 서버 패키지 설치** — npm 또는 pip로 설치 (1줄 명령)
2. **에이전트에 등록** — 도구별 설정 파일에 한 줄 추가
3. **에이전트 재시작 + 호출 테스트** — 트리거 한 번 보내서 동작 확인

대부분 *5~10분*이면 끝나요. 설치 자체는 어렵지 않은데, 처음에는 *어디에 등록하는지*가 도구마다 살짝 달라서 헷갈릴 수 있어요. 그건 가이드 실습에서 같이 봐드릴게요.

🛠 **미션** — 위 3단계 중 *어느 부분이 가장 걱정*되세요? "재시작하면 다른 게 깨질까봐", "패키지 설치가 처음이라" 등 짧게 적어주시면 실습 때 더 친절히 봐드릴게요.
