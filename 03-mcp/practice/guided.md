# Practice — 가이드 실습 (3강 MCP)

> `_shared/guided-practice-protocol.md`의 7단계 + 4-0절(draft 정리)을 따릅니다.

## 0. 진입 직전 (SKILL.md §4-0이 처리)

draft 정리 출력 후 *수정 사항이 없으면* 1단계로.

## 1. 옵션 제시 (3개)

```
어떤 MCP를 연결해보시겠어요?

  (1) filesystem MCP — 폴더 안 파일을 에이전트가 읽고 쓰기
  (2) memory MCP — 대화 기억을 장기 보관
  (3) 다른 MCP — {{name}}님이 직접 입력

번호로 답해주세요.
```

학습자 응답에 따라 `practice/options/` 안의 해당 파일 로드:
- (1) → `options/filesystem-mcp.md`
- (2) → `options/memory-mcp.md`
- (3) → `options/custom-mcp.md`

## 2. 공통 흐름 (옵션별 가이드는 옵션 파일에 있음)

각 옵션 가이드는 다음 7단계를 따름:
1. 옵션 선택 (위)
2. 사전 점검 — 필요한 런타임 (학습자 OS 맞춤)
3. 비용 안내 — MCP 자체 무료. 호출 시 LLM 비용은 별도 (간단 안내, 자유 스킵)
4. 설치 명령어 (학습자 OS 맞춤)
5. 등록 + 에이전트 재시작
6. 첫 호출 시연 — `draft.test_call` 채움
7. 검증 + 마무리

## 3. 검증 기준 (공통)

| 항목 | 통과 기준 |
|---|---|
| 설치 성공 | 명령어 실행 후 에러 없음 |
| 에이전트 인식 | 트리거로 호출 시 MCP가 응답 |
| 첫 호출 동작 | 결과가 *기대대로* 반환 |

3개 중 *2개 이상* 통과 시 ✅. 부족한 항목은 *명확히 명시*.

## 4. 트러블슈팅

옵션별 트러블슈팅은 `options/<id>.md` 안에 있음. 공통:
- 설치 실패 → npm/pip 권한 점검
- 인식 실패 → 에이전트 재시작
- 호출 실패 → 등록 위치 점검

## 5. 마무리

### 진도 갱신
- 통과: `practice_status = "done"`, `status = "completed"`
- 포기: `practice_status = "not_done"`
