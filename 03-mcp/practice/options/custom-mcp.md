# Option: 학습자 선택 MCP

## 한 줄 요약
filesystem·memory가 아닌 *다른 MCP*를 학습자가 직접 선택해서 연결합니다.

## 진입 시 학습자 선택 받기

```
어떤 MCP를 연결하고 싶으세요? 다음 중 하나 또는 직접 입력해주세요.

  - github MCP (GitHub 이슈/PR 조회)
  - sqlite MCP (작은 DB)
  - fetch MCP (웹 페이지 가져오기)
  - 기타 직접 입력
```

학습자 응답을 받고 *해당 MCP의 공식 패키지*를 검색.

## 사전 점검 (학습자 선택 MCP 기준)

- Node.js 또는 Python 런타임
- 해당 MCP가 요구하는 *외부 자격*(API 키, 인증 토큰 등)
- 권한 범위가 본인 환경에 안전한지

## 비용 안내

- 대부분 MCP 자체 무료
- 외부 API를 호출하는 MCP(github, fetch 등)는 *그 API의 요금*이 별도로 적용될 수 있음. 가입 페이지에서 확인 후 진행.

## 설치 → 등록 → 호출

filesystem·memory와 동일한 7단계. MCP 패키지 이름과 등록 설정만 다름.

## 트러블슈팅

선택한 MCP의 *공식 README*를 먼저 확인. 흔한 에러는 보통 거기에 정리되어 있음.

## 마무리 안내

직접 선택해 연결하신 MCP는 본인 작업에 가장 잘 맞을 거예요. 다음에 다른 MCP를 추가할 때도 같은 7단계로 진행하시면 됩니다.
