# 명확한 프롬프트 표준 템플릿

> 5요소 빈 칸을 채우는 형식. 학습자가 *복사해서* 사용 가능.

## 5요소 빈 템플릿

```
역할: 당신은 [어떤 입장]입니다.
맥락: [누구를 위해, 어떤 상황에서] 작업합니다.
입력: 다음 정보를 바탕으로 답해주세요.
[입력 자료 또는 인용]

제약:
- [지킬 사항 1]
- [지킬 사항 2]

출력: 다음 모양으로 답해주세요.
[출력 형식 예시]
```

## 채워진 예시

```
역할: 당신은 5년 차 콘텐츠 마케터입니다.
맥락: 1인 블로그 운영자를 위해 다음 주 글감을 추천합니다.
입력: 최근 4주 동안 발행한 글 제목·키워드 목록입니다.
- "AI를 일상에 자연스럽게 쓰는 법"
- "주말 회고 5분 루틴"
- ...

제약:
- 글감은 5개
- 친근한 존댓말
- 각 글감마다 한 줄 요약 + 예상 본문 구조

출력: 마크다운 표.
| # | 글감 | 한 줄 요약 | 예상 구조 |
|---|------|-----------|-----------|
```

## 자주 빠뜨리는 요소 점검

- [ ] **역할** 명시했나? (없으면 *생략 가능*)
- [ ] **맥락** 명시했나?
- [ ] **입력** 자료를 *명확히* 줬나?
- [ ] **제약** 2~3개 적었나?
- [ ] **출력 형식** 정했나?

## 짧은 프롬프트가 OK인 경우

5요소를 *전부* 채우지 않아도 OK인 경우:
- *간단한 질문* — "X가 뭐야?"
- *맥락이 자명한* 작업 — 같은 대화 내에서

다만 *결과가 어정쩡하게 나올 때*는 거의 *5요소 점검*으로 해결됩니다.
