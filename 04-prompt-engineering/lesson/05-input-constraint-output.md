# Lesson 4.5 — 입력·제약·출력 추가

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

이제 나머지 3요소 — *입력·제약·출력*을 더해볼게요.

직전 청크에서 적어주신 *역할 + 맥락 추가본*에 다음을 더해주세요:
- **입력**: 어떤 자료를 주는가? (예: 회의 노트, 첨부 파일)
- **제약**: 무엇을 지키나? (예: 한 페이지 이내, 친근한 존댓말)
- **출력**: 어떤 모양으로 받고 싶나? (예: 액션아이템 표 + 다음 회의 안건)

🛠 **미션** — 위 3요소를 *각 한 줄씩만* 적어 *명확한 프롬프트*를 완성하세요. 적용한 *원칙*도 1~2가지 짚어주시면 좋아요.

> 💾 적어주신 명확한 프롬프트는 자동으로 보관돼요. 실습에서 모호 vs 명확 두 버전을 *실제 호출*해 결과를 비교할 거예요.
