## 컴퓨터·터미널

### CLI (Command Line Interface)
명령어를 한 줄씩 입력하는 환경. 마우스 안 쓰고 키보드로만 작동. *터미널*이라고도 함.

### 디렉토리 (directory)
*폴더*와 같은 말. 파일을 담는 서랍.

### 명령어 (command)
컴퓨터에게 시키는 한 줄 지시. 예: `mkdir my-folder`는 "my-folder라는 폴더 만들어"라는 명령.

### 터미널 (terminal)
- **Mac**: Terminal 앱 (Spotlight에서 "터미널" 검색)
- **Windows**: PowerShell (시작 메뉴에서 검색)
검은 창이 뜨면 그게 터미널이에요.

### 권한 / 관리자 권한
- **일반 권한**: 본인 폴더만 읽고 쓰기
- **관리자 권한**: 시스템 전체 변경 가능. *Mac sudo*, *Windows 관리자 권한으로 실행*. 위험할 수 있어 신중히.

### PATH
시스템이 *명령어를 찾는 폴더 목록*. `npm install -g`로 설치한 패키지가 PATH에 없으면 명령어를 못 찾음.

## Git·GitHub

### Git
파일 변경을 *시간 순으로 기록*하는 도구. 본인 컴퓨터에서 동작.

### GitHub
Git 저장소를 *온라인에 올릴 수 있는 사이트*. github.com.

### 커밋 (commit)
변경 사항을 *한 시점에 저장*. 게임의 세이브 포인트.

### 푸시 (push)
본인 컴퓨터의 Git 저장소를 *GitHub에 올리기*.

### 풀 (pull)
GitHub에서 *본인 컴퓨터로 내려받기*.

### PR (Pull Request)
"내가 이렇게 바꿨는데 합쳐줘"라는 제안. 회사의 결재 올림과 비슷.

### 저장소 / 리포지토리 (repository, repo)
Git이 관리하는 *코드 폴더 한 덩어리*.

### 별 (star)
GitHub에서 *좋아요* 같은 표시. 별이 많으면 *유명·검증된* 자료.

### 이슈 (issue)
저장소에 *문제·제안*을 적는 게시글.

## 파일·코드

### JSON
정보를 *프로그램이 읽기 쉽게* 적는 표준 형식.
```json
{
  "이름": "매튜",
  "직업": "강의 작성자"
}
```

### YAML / Frontmatter
JSON과 비슷하지만 *사람이 읽기 더 쉬운* 형식. SKILL.md 상단의 `---`로 둘러싸인 부분.

### 마크다운 (markdown)
텍스트에 *굵게·제목·목록* 같은 서식을 *간단한 기호*로 적는 방식. `# 제목`, `**굵게**`, `- 목록` 등.

### .env 파일
환경 변수를 적어두는 *비밀 파일*. `.env`로 시작 (점이 앞에).

### .gitignore
"이 파일들은 git에 안 올린다"고 적는 *무시 목록*.

## API·인증

### API (Application Programming Interface)
프로그램끼리 *대화하는 통로*. 사람이 사이트를 브라우저로 보듯, 프로그램은 API로 데이터 주고받음.

### API 키 / 토큰
API를 쓸 때 필요한 *비밀번호*. 절대 외부에 노출 X.

### 환경 변수 (environment variable)
시스템에 *전역 저장된 값*. 매번 입력 안 해도 프로그램들이 자동으로 가져옴. API 키 보관에 자주 사용.
{{os:darwin}}
설정 예: `export ANTHROPIC_API_KEY="sk-..."`
{{/os}}
{{os:win32}}
설정 예: `[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-...", "User")`
{{/os}}

### 엔드포인트 (endpoint)
API의 *특정 주소*. 예: `https://api.anthropic.com/v1/messages`

### 인증 (authentication)
"누구인지 확인". API 키, OAuth, 토큰 등 다양한 방식.

### 401 / 403 / 429
HTTP 에러 코드:
- **401**: 인증 실패 (키 잘못)
- **403**: 권한 없음
- **429**: 한도 초과 (너무 자주 호출)

## 도구·실행

### Docker
프로그램을 *박스에 담아 띄우는* 도구. 본인 컴퓨터 환경에 영향 없이 깔끔하게 사용. 10강에서 n8n을 Docker로.

### 컨테이너 (container)
Docker가 띄운 *박스 하나*. 안에서 프로그램이 돌아감.

### 이미지 (image)
컨테이너의 *원본 청사진*. 같은 이미지로 컨테이너 여러 개 띄울 수 있음.

### npm
JavaScript 패키지 설치 도구. `npm install -g <패키지명>`.

### pip
Python 패키지 설치 도구. `pip install <패키지명>`.

### 패키지 (package)
다른 사람이 만든 *재사용 가능한 코드 묶음*. npm·pip·apt 등으로 설치.

### 포트 (port)
컴퓨터의 *통신 창구 번호*. 같은 컴퓨터에 여러 프로그램이 *서로 다른 포트*로 동시에 동작.
- 80: 일반 웹 (HTTP)
- 443: 보안 웹 (HTTPS)
- 5678: n8n 기본 포트

### 로그 (log)
프로그램이 *동작 중에 남기는 기록*. 에러·경고·정보 등.

### 에러 메시지 (error message)
프로그램이 *문제가 생겼을 때* 알려주는 한 줄. 마지막 줄에 *근본 원인*이 자주 나옴.

## LLM·에이전트

### LLM (Large Language Model)
*큰 언어 모델*. Claude, GPT, Gemini 등.

### 토큰 (token)
LLM이 글을 *세는 단위*. 영어 1단어 ≈ 1토큰, 한국어 1글자 ≈ 1.5~2토큰.

### 컨텍스트 윈도우 (context window)
LLM이 *한 번에 볼 수 있는* 글의 양. 도구마다 다름 (보통 수만~수십만 토큰).

### 프롬프트 (prompt)
LLM에게 시키는 *한 마디*. "글 좀 써줘"가 가장 짧은 프롬프트.

### MCP (Model Context Protocol)
에이전트와 외부 도구를 잇는 *표준 다리*. 3강에서 다룸.

### hook
*특정 이벤트가 일어났을 때* 자동으로 발사되는 작은 작업. 9강에서 다룸.

### 서브에이전트 (subagent)
큰 작업의 *일부를 위임*받는 다른 에이전트. 8강에서 다룸.

### 워크플로우 (workflow)
여러 단계를 *순서대로* 또는 *분기*로 연결한 자동화. 10강에서 n8n으로.
