# Lesson 0.2 — 미리 가입해두면 좋은 곳

> 이 파일은 *한 청크*를 담고 있습니다. 강의 진행 중 가입이 필요할 수 있는 사이트를 미리 안내합니다.

## Chunk 1

본 강의 1~15강을 진행하다 보면 *몇 군데 가입*이 필요할 수 있어요. 미리 알아두시면 *진행이 끊기지* 않아요.

### 가입 *권장* (대부분 강의에서 사용)

| 사이트 | 어디서 쓰나 | 무료/유료 | 카드 필요 |
|---|---|---|---|
| **GitHub** ([github.com](https://github.com)) | 일부 패키지 설치, 커뮤니티 자료 다운로드 | 무료 | 필요 X |
| **Docker Hub** ([hub.docker.com](https://hub.docker.com)) | 10강 n8n 설치 시 | 무료 | 필요 X |

GitHub은 *가입만* 해두시면 1강~15강 어디서도 *대부분 작업이 가능*해요. Docker Hub는 *Docker 설치 후* 첫 사용 시 자동으로 가입되는 경우 많음.

### 가입 *선택* (해당 강의 들으실 때만)

⚠ 다음 사이트는 *6강(API)* 또는 *비용 발생 가능성*이 있는 강의에서만 필요해요. *지금 안 가입하셔도 됩니다*. 해당 강의 시작 시 다시 안내드려요.

| 사이트 | 어디서 쓰나 | 무료/유료 | 카드 필요 |
|---|---|---|---|
| Anthropic Console | 6강, Claude API | 신규 크레딧 (변동 가능) | 가능성 있음 |
| Google AI Studio | 6강, Gemini API | 일일 한도 무료 (변동 가능) | 보통 X |
| OpenRouter | 6강, 여러 모델 | 일부 모델 무료 | 가능성 있음 |

### *나중에* 가입할 곳

- **VS Code** ([code.visualstudio.com](https://code.visualstudio.com)) — 99 부록의 VS Code 확장 강의 들으실 때만
- **Claude Desktop** — 99 부록의 다중 세션 강의 때

### 미리 준비해두면 더 좋은 것

- 이메일 주소 1개 (가입에 사용 — Gmail, 회사 메일 등)
- (선택) 결제 카드 (6강의 일부 옵션에 필요할 수 있음 — *지금은 안 하셔도 OK*)
- (선택) Google 계정 (Google AI Studio가 가장 부담 적음)
