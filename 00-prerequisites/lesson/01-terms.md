# Lesson 0.1 — 자주 막히는 용어 사전

> 이 파일은 *한 청크*를 담고 있습니다. 본 강의에서 자주 나올 용어 10여 가지를 *비유와 예시*로 짧게 설명합니다.

## Chunk 1

본 강의에서 다음 용어들이 자주 나와요. 처음 보시면 낯설 수 있어 미리 한 번 훑고 갈게요.

### 컴퓨터·터미널
- **CLI / 터미널**: 명령어를 한 줄씩 입력하는 *검은 창*. Mac에선 *Terminal* 앱, Windows에선 *PowerShell*. 마우스 안 쓰고 키보드로 컴퓨터에게 직접 시키는 도구예요.
- **디렉토리 / 폴더**: 같은 말이에요. 파일을 담는 *서랍*. CLI에선 *디렉토리*라고 부르는 경우가 많아요.
- **권한 / 관리자 권한**: 시스템에 *변경할 수 있는 자격*. 관리자 권한은 *모든 폴더에 손댈 수 있는* 강한 자격이에요.

### Git·GitHub (코드 공유)
- **Git**: 파일 변경을 *시간 순으로 기록*하는 도구. "어제 어디까지 했지?"를 기록해둬요.
- **커밋(commit)**: 변경 사항을 *저장한 한 시점*. 게임의 *세이브 포인트*와 비슷해요.
- **저장소 / 리포지토리(repo)**: Git이 관리하는 *코드 폴더 한 덩어리*. GitHub는 그 폴더를 *온라인에 보관*해줘요.
- **별(star)**: GitHub 저장소에 *좋아요* 누르는 것. 별이 많으면 *유명·검증된* 자료라는 신호.
- **PR / Pull Request**: "내가 이렇게 바꿨는데 합쳐줘" 라는 *제안*. 회사로 치면 *결재 올림*이에요.

### API·인증
- **API**: 프로그램끼리 *대화하는 통로*. {{name}}님이 사람용 사이트를 *브라우저로* 보듯, 프로그램은 *API로* 정보를 주고받아요.
- **API 키 / 토큰**: API를 쓸 때 필요한 *비밀번호*. 절대 외부에 노출하면 안 돼요.
- **JSON**: 정보를 *프로그램이 읽기 쉽게* 적는 표준 형식. 사람도 보면 알 수 있어요. 예: `{"이름": "매튜", "직업": "강의 작성자"}`

### 환경·설치
- **환경 변수**: 시스템에 *전역으로 저장된* 값. 매번 입력하지 않아도 프로그램들이 자동으로 가져다 써요. API 키 보관에 자주 사용.
- **PATH**: 시스템이 *명령어를 찾는 폴더 목록*. PATH에 추가된 폴더의 명령어는 어디서든 실행 가능.
- **포트**: 컴퓨터의 *통신 창구 번호*. n8n은 5678번 포트, 웹 서버는 80·443 등.
- **Docker / 컨테이너**: 프로그램을 *통째로 박스*에 담아 띄우는 도구. *내 컴퓨터 환경에 영향 없이* 깔끔하게 사용. 10강에서 n8n을 Docker로 띄워요.
- **npm / pip**: 프로그램 설치 도구. *npm*은 JavaScript용, *pip*는 Python용.
