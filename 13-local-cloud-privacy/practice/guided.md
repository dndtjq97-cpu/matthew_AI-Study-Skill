# Practice — 가이드 실습 (13강 로컬·클라우드·프라이버시)

> `_shared/guided-practice-protocol.md`의 7단계를 따릅니다.

## 0. 진입 직전 (draft 정리)

이론에서 적은 `sensitive_data_list` / `routing_rule` / `local_llm_choice`를 정리해 보여줌.

## 1. 옵션 제시 (2개 인라인, 둘 다 OK)

```
어떤 길로 가시겠어요? 둘 다 하셔도 OK.

  (1) {{name}}님 본인 데이터를 3등급으로 분류 + 라우팅 규칙 만들기
  (2) (선택) 로컬 LLM 1개 설치해보기 (Ollama 등)
```

## 2. 옵션 ① — 본인 데이터 분류 + 라우팅 규칙

### 2-1. 데이터 분류 점검
이론에서 적어주신 분류를 다시 보고 *2~3개씩* 추가:
- 🟢 1급(공개 OK)
- 🟡 2급(주의)
- 🔴 3급(절대 클라우드 X)

각 등급에 대해 *본인 작업의 실제 데이터*를 1~2개씩 떠올림.

### 2-2. 라우팅 규칙 한 줄
```
1급 → 클라우드 (어떤 도구든 OK)
2급 → 익명화 후 클라우드 또는 로컬
3급 → 로컬에서만
```

위 기본 규칙을 *본인 환경에 맞춰* 다듬기.

### 2-3. AGENTS.md에 규칙 반영 (선택)

학습자가 1강에서 만든 AGENTS.md에 *주의사항* 항목으로 추가:
```
## 주의사항
- 민감 데이터는 .private/ 폴더에만 저장
- 3급 데이터는 외부 LLM 호출에 포함하지 않기
```

## 3. 옵션 ② — 로컬 LLM 설치 (선택)

### 3-1. 사전 점검
- 디스크 공간 4~7GB 여유 (작은 모델 기준)
- 메모리 8GB 이상 권장

### 3-2. Ollama 설치 (학습자 OS 맞춤)

{{os:darwin}}
```bash
# Homebrew로 설치
brew install ollama

# 또는 공식 설치 스크립트
curl -fsSL https://ollama.com/install.sh | sh

# 백그라운드 시작
ollama serve &
```
{{/os}}

{{os:win32}}
```powershell
# Ollama Windows 설치 페이지에서 다운로드
Start-Process https://ollama.com/download/windows
```
{{/os}}

### 3-3. 모델 다운로드 + 첫 호출

```bash
# 작은 모델 다운로드 (4GB)
ollama pull llama3.2:3b

# 첫 호출
ollama run llama3.2:3b "안녕!"
```

응답이 오면 *로컬 LLM* 첫 시연 ✅. 데이터는 외부로 안 나갔어요.

## 4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 3등급 분류가 *적어도 2등급* 채워짐 | ✅ |
| `routing_rule`이 *실행 가능*한 한 줄 | ✅ |
| (선택) 로컬 LLM 첫 호출 성공 | ✅ (옵션) |

옵션 ① 단독 진행 시 *위 1·2번만으로* ✅.

## 5. 트러블슈팅

- 디스크 공간 부족 → 더 작은 모델 (`gemma3:1b` 등) 또는 옵션 ① 단독
- 로컬 LLM 응답 느림 → CPU 환경에선 정상. GPU 있으면 더 빠름.
- 라우팅 규칙이 모호함 → *예시 데이터 5개*로 자가 테스트
