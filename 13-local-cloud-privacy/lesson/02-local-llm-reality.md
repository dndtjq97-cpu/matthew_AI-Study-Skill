# Lesson 13.2 — 로컬 LLM의 현실

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

**로컬 LLM**은 본인 컴퓨터에서 도는 LLM이에요. 데이터가 외부로 안 나가요. 다만 *현실*을 알아둘 필요가 있어요.

장점:
- ✅ 데이터 유출 위험 0
- ✅ 비용 0 (전기·디스크 빼고)
- ✅ 인터넷 없어도 동작

단점:
- ⚠ *정확도가 클라우드보다 낮음* (특히 작은 모델)
- ⚠ 디스크 공간 4~30GB 필요
- ⚠ 컴퓨터가 *조금 느려질 수* 있음

**원칙**: 로컬 LLM은 *민감 데이터 + 단순 작업*에 적합. 어려운 작업은 *클라우드가 안전한 데이터*에서 사용.
