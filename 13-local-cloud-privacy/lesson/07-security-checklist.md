# Lesson 13.7 — 보안 체크리스트

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

마지막으로 *전체 보안 체크리스트*를 점검해볼게요.

기본 5가지:
- [ ] **API 키** — 코드에 직접 박혀 있지 않다
- [ ] **3등급 분류** — 본인 데이터에 적용했다
- [ ] **라우팅 규칙** — 한 줄로 명확하다
- [ ] **민감 폴더 격리** — `.private/` 같은 폴더는 *AGENTS.md*에서 *접근 금지*로 명시
- [ ] **로그 점검** — API 응답·에이전트 로그에 민감 데이터가 *반복 기록*되지 않는다

이 5가지만 챙기면 *대부분의 사고*는 막을 수 있어요. 더 엄격한 환경(의료·금융 등)은 추가 점검이 필요하지만, 일반 작업에는 이 정도면 충분합니다.

❓ 위 5가지 중 본인이 *아직 안 하시던* 것이 있다면 어떤 거예요?
