# Lesson 13.3 — 데이터 분류 기준 (3등급)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

데이터를 *3등급*으로 나누면 *어디에 보낼지*가 자동으로 결정돼요.

| 등급 | 종류 | 예시 | 어디로? |
|---|---|---|---|
| 🟢 1급 | 공개 OK | 블로그 글 초안, 공개 문서 | 클라우드 OK |
| 🟡 2급 | 주의 | 회사 내부 회의록, 개인 일정 | *익명화 후* 클라우드 또는 로컬 |
| 🔴 3급 | 절대 클라우드 X | 비밀번호, 의료·법률 정보, 금융 | 로컬 only |

이 3등급 기준만 가지고도 *대부분의 데이터*는 자동 분류돼요. 애매한 데이터는 보수적으로 *상위 등급*으로 보세요.

🛠 **미션** — 본인 작업의 데이터를 3등급으로 *2~3개씩만* 분류해서 적어주세요. 짧게 OK.

> 💾 적어주신 분류는 자동 보관됩니다. (`draft.sensitive_data_list`)
