# 본인 하네스 통합 체크리스트

## 1. AGENTS.md 종합 정비 (1강 + 강의 통찰)

기본 6섹션:
- [ ] 프로젝트 개요 (한 단락)
- [ ] 톤과 스타일
- [ ] 자주 쓰는 명령
- [ ] 주의사항
- [ ] 도구·환경 (선택)
- [ ] 예시 (선택)

강의 통찰 추가 항목:
- [ ] 컨텍스트 관리 규칙 (5강) — "외부 메모리 사용", "긴 첨부 X"
- [ ] 데이터 라우팅 규칙 (13강) — "민감 데이터는 로컬"
- [ ] 모델·캐싱 정책 (12강) — "단순 작업은 작은 모델"
- [ ] 자동화 원칙 (8·9강) — "큰 작업은 위임", "반복은 hook"

## 2. skills 모음 (2강 + 추가)

- [ ] 2강 첫 스킬 (있으신지)
- [ ] 추가 스킬 후보 (1~2개):
  - [ ] 4강 → "프롬프트 다듬기 도우미"
  - [ ] 7강 → "디버깅 체크리스트 적용"
  - [ ] 12강 → "비싼 호출 점검"
  - [ ] 14강 → "멀티에이전트 라우터"
- [ ] 모든 스킬을 *한 폴더*에 통합

## 3. MCP / hooks / subagents (3·8·9강)

- [ ] 3강 MCP 1개 이상 등록·동작 확인
- [ ] 9강 hook 1개 발사 정상
- [ ] 8강 서브에이전트 패턴 *적용 시점* 명시 (AGENTS.md에)

## 4. 운영 환경 점검

- [ ] 6강 API 키 안전 보관 (코드에 직접 X)
- [ ] 12강 비용 대시보드 *주 1회* 확인 습관
- [ ] 13강 민감 폴더 (`.private/` 등) 격리 + `.gitignore`

## 5. 일일 운영 루틴 (한 페이지)

```
# 매일 운영 루틴

## 시작 시 (1분)
- [ ] 어제 NOTES.md 검토
- [ ] 오늘 작업 1~2가지 결정

## 작업 중 (수시)
- [ ] 자주 쓰는 스킬은 트리거로 호출
- [ ] 부족한 부분은 NOTES.md 한 줄 메모

## 작업 끝마다 (수시)
- [ ] 새 작업이면 새 대화창
- [ ] 결정 사항은 decisions.md에 한 줄

## 종료 시 (1분)
- [ ] 내일 첫 작업 한 줄 메모

## 주 1회 (10분)
- [ ] 비용 대시보드 점검
- [ ] AGENTS.md·SKILL.md 가벼운 다듬기
- [ ] NOTES.md 정리 (오래된 항목 제거 또는 결정으로 승격)
```

## 6. 빈 부분 처리

체크리스트에서 *비어 있는 항목*은 캡스톤 종료 시 *해야 할 일 1개*로 메모:

```
# 다음에 할 일

- [ ] 4강 실습 미이행 → 본인 프롬프트 1개 다듬기
- [ ] 8강 서브에이전트 적용 → 본인 작업의 위임 가능 부분 1개
- [ ] 6강 API 키 미발급 → 시간 날 때 무료 옵션부터
```

이 메모를 NOTES.md 상단에 두고 *천천히* 처리. 한 번에 다 하지 않아도 OK.

## 7. 1주일 운영 후 자가 평가

체크리스트로 자가 점검:
- [ ] 매일 루틴이 *부담 없이* 따라지는가?
- [ ] 에이전트가 *일관된 톤*으로 답하는가?
- [ ] 같은 부탁을 *반복*하지 않는가?
- [ ] 비용·컨텍스트가 *통제되고* 있는가?

문제 있으면 *AGENTS.md / SKILL.md* 가벼운 수정. 매주 조금씩 다듬는 게 가장 효과적입니다.
