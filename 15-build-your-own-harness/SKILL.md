# Lesson 15 — 🎯 본인만의 하네스 구축 (캡스톤)

> 학습자가 끝나면 1~14강에서 만든 모든 요소를 *본인의 진짜 작업 환경*에 통합한 하네스를 완성한다.

이 강의는 강의 패키지의 **종착점**입니다. 새 개념을 배우는 게 아니라, *이미 만든 것들을 한 곳에 모아 운영 가능한 환경으로 합치는* 통합 작업입니다.

---

## 0. 시작하기 전에
공통 5개 문서 참조.

## 1. 진입 시 행동

1. 학습자 프로필 확인.
2. `progress["15-build-your-own-harness"].status` 분기.
3. **선행 점검** — 1~14강 진도를 *체크리스트*로 보여줌:
   ```
   캡스톤은 1~14강에서 만든 산출물을 *통합*하는 강의예요.
   {{name}}님의 진도를 점검해볼게요.

     [✅] 1강 AGENTS.md
     [⚠] 2강 skills (실습 미이행)
     [✅] 3강 mcp
     [🔒] 4강 prompt-engineering
     ...

   미수강·미이행 강의가 있어요. 어떻게 하시겠어요?
     (1) 그래도 캡스톤 진행 (없는 부분은 옵션 ②로 처리)
     (2) 먼저 미수강 강의로 돌아가기
   ```
4. 첫 인사 + "긴 여정의 마지막에 오신 걸 환영해요!" 격려.
5. 이론 진입. 헤더 `📘 [Lesson 15 · 청크 X/Y]`.
6. 이론 끝 → 가이드 실습 (옵션 2개 인라인).
7. 실습 종료 → 진도 갱신 + **🎓 강의 패키지 완주** 마무리.

|---|---|---|

| `daily_workflow` | 청크 7 | string (운영 루틴) |

## 3. 이론 lesson 흐름

청크 8개. *통합* 강의라 패턴이 다른 강의와 약간 다름:
1. 하네스란? 지금까지 만든 것 모아보기
2. 본인 환경 점검 — 어디까지 적용했나?
3. 통합 우선순위 정하기
4. AGENTS.md 종합 정비 (1강 산출물 다듬기)
5. skills 모음 정리 (2강 + 추가)
6. MCP / hooks / subagents 통합 (3·8·9강)
7. 운영 루틴 만들기 — `daily_workflow`
8. 마무리 — 이후에 무엇을?

### 15강에서 *왜* 한 청크씩 가는가
캡스톤은 *통합*이라 한 번에 다 하면 어디서부터 손대야 할지 막혀요. 한 청크씩 *어떤 산출물부터 → 어떻게 합칠지 → 다음*으로 가야 매튜님이 *우선순위*를 정하며 하나씩 정비할 수 있습니다.

## 4. 가이드 실습 — 옵션 2개 인라인

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 진짜로 하네스를 완성해볼 시간이에요.

📝 하네스 한 줄 정의: <draft.harness_overview>
📝 사용한 컴포넌트:
   - AGENTS.md: <draft.components_used.agents_md>
   - skills: <draft.components_used.skills>
   - MCP: <draft.components_used.mcp>
   - hooks/subagents: <draft.components_used.hooks_subagents>
📝 일일 운영 루틴: <draft.daily_workflow>
```

### 4-1. 옵션 제시

```
어떻게 진행하시겠어요?

  (1) 1~14강의 *본인 산출물*을 통합 (가장 추천)
       (실습들에서 만든 것들이 자동으로 합쳐져요)
  (2) 새로운 도메인에 처음부터 적용
       (강의 다 안 들으셨거나, 새 환경에 적용하실 때)

번호로 답해주세요.
```

### 4-2. 옵션 ① — 본인 산출물 통합

학습자 프로필의 `progress[*].draft`를 모두 읽어 *각 강의 결과물*을 모아 보여줌. 학습자에게:
1. AGENTS.md 종합본 만들기 (1강 + 다른 강의 통찰)
2. skills 폴더 정리 (2강 + 14강 동안 만든 추가 스킬들)
3. MCP/hooks/subagents 등록 상태 점검
4. 일일 루틴 체크리스트 작성

### 4-3. 옵션 ② — 새 도메인 처음부터

새 폴더 만들고 *최소 하네스* 구축: AGENTS.md + 1~2개 핵심 skill만.

### 4-4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| `harness_overview`가 *한 줄로 명확* | ✅ |
| `components_used`에 *3개 이상* 컴포넌트 | ✅ |
| `daily_workflow`가 *실제로 매일 사용 가능*한 형태 | ✅ |

3개 중 2개 이상 ✅.

## 8. 강의 작성자 메타

- **트랙**: 캡스톤 (capstone)
- **선행**: 1~14강 (강력 권장 — 모두 수강 또는 스킵 처리됨)
- **분량**: 약 30~45분 (통합 작업이라 학습자별 차이 큼)
- **외부 자료**: 학습자가 1~14강에서 만든 모든 산출물
- **비용**: 없음
- **학습 목표**:
  - 1~14강 산출물을 한 폴더 안에 *통합*
  - 매일 사용 가능한 *운영 루틴* 작성
  - 본인 환경에서 *어떤 부분이 비어 있는지* 인지하고 보완 계획 수립
- **다음**: 99-claude-specific 부록 (선택)
