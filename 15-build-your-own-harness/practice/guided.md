# Practice — 🎯 가이드 실습 (캡스톤)

> 학습자가 1~14강에서 만든 모든 산출물을 *본인 환경*에 통합한 하네스를 완성합니다.

## 0. 진입 직전

학습자 프로필의 1~14강 `progress[*].draft`를 모두 읽어 *체크리스트*로 보여줌.

```
🎉 캡스톤에 오신 걸 환영해요, {{name}}님!

지금까지 만드신 산출물을 점검해볼게요.

  [✅] 1강 AGENTS.md (1강에서 만든 파일)
  [✅] 2강 SKILL.md (2강에서 만든 첫 스킬)
  [⚠] 3강 MCP — 이론 OK, 실습 미이행
  ...

비어 있는 부분이 있어도 괜찮아요. 캡스톤은 *적용한 것들을 통합*하면서
빈 부분에 *해야 할 일 1개*씩만 메모해두면 충분합니다.
```

이론에서 적은 `harness_overview` / `components_used` / `daily_workflow`도 정리.

## 1. 옵션 제시 (2개 인라인)

```
어떻게 진행하시겠어요?

  (1) 1~14강 본인 산출물 통합 (가장 추천 — 강의 다 들으셨으면)
  (2) 새로운 도메인에 처음부터 적용 (강의 다 안 들으셨거나, 다른 환경에)

번호로 답해주세요.
```

## 2. 옵션 ① — 본인 산출물 통합

### 2-1. AGENTS.md 종합 정비
1강에서 만든 AGENTS.md를 *지금 다시 보면서* 다음 항목을 추가:
- 5강 컨텍스트 관리 규칙
- 13강 데이터 라우팅 규칙
- 12강 모델·캐싱 정책
- 8·9강 자동화 항목

### 2-2. skills 모음 정리
- 2강 스킬 외에 *추가로 만들 만한 스킬 1~2개* 결정
- 한 폴더(`~/.claude/skills/` 등)에 모아 두기

### 2-3. MCP / hooks / subagents 통합
- 3강 MCP가 등록되어 있는지 점검
- 9강 hook 발사 동작 확인
- 8강 서브에이전트 패턴 유효성 점검

### 2-4. 운영 루틴 작성
`draft.daily_workflow`를 토대로 *매일 사용할 루틴*을 한 페이지로 정리:

```
# 매일 운영 루틴

## 시작 시 (1분)
- [ ] AGENTS.md, NOTES.md 가벼운 점검
- [ ] 어제 남은 작업 확인

## 작업 중 (수시)
- [ ] 자주 쓰는 스킬은 트리거로 호출
- [ ] 부족한 부분은 NOTES.md에 한 줄 메모

## 종료 시 (1분)
- [ ] 새 작업이면 다음 대화 분리
- [ ] 비용 대시보드 한 번 보기 (주 1회)
```

## 3. 옵션 ② — 새 도메인 처음부터

새 폴더 만들고 *최소 하네스* 구축:
- AGENTS.md 1장
- SKILL.md 1~2개
- 일일 루틴 한 페이지

이 정도만 있어도 *시작 가능한 하네스*입니다.

## 4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| `harness_overview`가 *한 줄로 명확* | ✅ |
| `components_used`에 *3개 이상* 컴포넌트 | ✅ |
| `daily_workflow`가 *매일 사용 가능*한 형태 | ✅ |

3개 중 *2개 이상* 통과 시 ✅.

## 5. 🎓 강의 패키지 완주 마무리

```
🎉🎉🎉 강의 패키지 완주 축하드려요, {{name}}님!

여기까지 오신 게 정말 큰일이에요. 1~14강에서 만든 것들이 이제 하나의
운영 가능한 하네스로 합쳐졌습니다.

📋 {{name}}님의 하네스 요약:
   - 한 줄 정의: <draft.harness_overview>
   - 통합한 컴포넌트: <draft.components_used 개수>개
   - 일일 운영 루틴: 작성 완료

이후에 무엇을 할까요?
  (1) 강의 패키지의 부록(99-claude-specific) 살펴보기
  (2) 본인 환경에서 1주일 운영해보고 다시 돌아오기
  (3) 강의 종료

이 강의 패키지는 {{name}}님 작업의 *시작*이에요. 천천히 본인 페이스로
사용하세요.
```

### 진도 갱신
- 캡스톤 통과: `status = "completed"`, `practice_status = "done"`, `track = "capstone"`
- 패키지 전체 완주 알림.
