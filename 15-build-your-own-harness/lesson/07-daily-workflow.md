# Lesson 15.7 — 운영 루틴 만들기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

마지막은 *매일 사용할 운영 루틴*이에요. 하네스가 아무리 좋아도 *매일 어떻게 쓸지*가 정해져야 진짜로 활용됩니다.

추천 루틴 구조:
1. **시작 시 점검** — AGENTS.md, 진행 중인 작업 확인 (1분)
2. **반복 작업 자동 호출** — 자주 쓰는 skill을 자연어로 부름 (수시)
3. **결과 검토 + 개선 메모** — 잘 안 된 부분은 NOTES.md에 한 줄 메모 (수시)
4. **종료 시 정리** — 새 작업이면 새 대화창으로 분리 (1분)

이 정도가 *부담 없는 일상 루틴*이에요. 더 복잡한 루틴은 *익숙해진 다음에* 추가하세요.

🛠 **미션** — 본인 *일일 운영 루틴*을 3~4단계로 적어주세요. 위 추천을 그대로 쓰셔도 OK.

> 💾 답변은 자동 보관됩니다. (`draft.daily_workflow`)
