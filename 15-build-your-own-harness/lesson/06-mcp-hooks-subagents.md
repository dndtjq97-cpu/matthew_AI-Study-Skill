# Lesson 15.6 — MCP / hooks / subagents 통합

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

3·8·9강에서 만든 *외부 도구 연결, 위임, 자동화 트리거*를 *한 환경*에 통합하면 시너지가 나요.

통합 패턴 예시:
- **MCP + skill** — MCP로 데이터 가져오는 skill
- **hook + skill** — hook이 트리거 → skill 실행
- **subagent + skill** — skill이 서브에이전트 호출

이런 통합은 *처음부터 다 만들 필요 없어요*. 본인이 가장 자주 하는 작업에 *1~2 통합*만 적용해도 효과가 크게 느껴집니다.

🛠 **미션** — 위 통합 패턴 중 *본인 환경에 가장 자연스러운 1가지*를 떠올려주세요.
