## 0. 진입 직전

이 단계는 SKILL.md §4-0에서 이미 처리합니다 (`progress["01-agents-md"].draft` 정리해서 학습자에게 보여주기). 이 파일에서는 정리 출력 *이후*부터 시작합니다.

학습자가 정리된 draft를 보고:
- "그대로 좋아요" / 무응답 → 1단계로
- "개요 수정" / "규칙 수정" / "명령 수정" / "주의 수정" → 해당 키 다시 입력 받고 덮어쓰기 → 정리 다시 보여주기

## 1. 옵션 제시

```
이제 직접 AGENTS.md를 만들어볼게요. 어디에 만드시겠어요?

  (1) 새 폴더 — 빈 폴더를 새로 만들고 처음부터 작성
       (이게 처음이시라면 추천 — 깨끗한 환경에서 시작)
  (2) 기존 프로젝트 — {{name}}님이 이미 가진 폴더에 추가

번호 또는 "1번", "2번"으로 답해주세요.
```

학습자 응답에 따라 옵션 ① 또는 ②로 분기.

## 옵션 ① — 새 폴더

### 1-1. 폴더 위치 묻기

```
좋아요! 새 폴더에 만들 거예요. 어디에 만드시겠어요?

추천 위치는 다음 중 하나예요:
  - Documents 폴더 안 (예: my-agent-test)
  - Desktop 폴더 안

원하시는 위치/이름을 알려주시거나, "추천 위치로 해주세요"라고 답하셔도 OK.
```

학습자가 답하면 그 위치에 폴더를 만듭니다.

### 1-2. 사전 점검

이 실습은 **비용이 들지 않아요**. 별도 비용 안내 없이 진행합니다.

필요한 것은:
- 터미널/CLI 접근 권한
- AGENTS.md 파일 1개 만들 정도의 디스크 공간 (1KB 미만)

### 1-3. 명령어 안내 — OS 맞춤

학습자 프로필 `os` 값을 보고 *해당 OS 명령*만 출력합니다.

{{os:darwin}}
```bash
# 폴더 만들기 (학습자가 답한 위치/이름 사용)
mkdir -p ~/Documents/my-agent-test

# 그 폴더로 이동
cd ~/Documents/my-agent-test

# AGENTS.md 빈 파일 만들기
touch AGENTS.md
```
{{/os}}

{{os:win32}}
```powershell
# 폴더 만들기 (학습자가 답한 위치/이름 사용)
New-Item -ItemType Directory -Force -Path "$HOME\Documents\my-agent-test"

# 그 폴더로 이동
Set-Location "$HOME\Documents\my-agent-test"

# AGENTS.md 빈 파일 만들기
New-Item -ItemType File -Path AGENTS.md
```
{{/os}}

### 1-4. 결과 확인

```
실행하셨으면 "됐어요" 또는 화면에 뜬 메시지를 알려주세요.
오류가 났다면 메시지를 그대로 붙여넣어 주세요. 같이 풀어볼게요.
```

→ 성공 시 1-5로, 실패 시 트러블슈팅(아래) 참조.

### 1-5. AGENTS.md 초안 작성 (에이전트 주도)

학습자 draft를 토대로, 에이전트가 AGENTS.md *초안 전체*를 작성하고 학습자에게 보여줍니다.

표준 출력 형식:

```
좋아요. {{name}}님이 적어주신 내용을 토대로 AGENTS.md 초안을 만들어볼게요.

# AGENTS.md 초안

## 프로젝트 개요
<draft.overview>

## 톤과 스타일
<draft.rules 전체 — 톤·형식·행동 규칙을 이 섹션에 모음>

## 자주 쓰는 명령
<draft.commands>

## 주의사항
<draft.cautions>

## 도구·환경 (선택 — 이번 강의에선 안 적었어요)
*시간 나실 때 사용 중인 언어·라이브러리·주요 서비스를 추가하시면 더 든든해요. 형식은 `resources/agents-md-template.md`를 참고하세요.*

## 예시 (선택 — 이번 강의에선 안 적었어요)
*시간 나실 때 잘된 결과물·안 된 결과물 한두 개씩 추가하시면 좋아요.*

---

이 내용 그대로 파일에 넣을까요?
  (1) 네, 좋아요 — 파일에 저장하고 다음으로
  (2) 어떤 부분을 수정하고 싶어요 — 어디를 어떻게 바꿀지 알려주세요
```

학습자가 (1) 응답 → 다음 단계.
학습자가 (2) 응답 → 해당 부분 다듬어서 다시 보여주기 → 반복.

> 💡 학습자가 "어떤 게 좋은 톤이지?" 같은 질문을 하면 SKILL.md `lesson/05`의 안내를 참조해 짧게 답합니다.

### 1-6. 파일에 저장

학습자가 OK 한 초안을 *실제 AGENTS.md 파일에* 씁니다. 두 가지 방식:

**(A) 에이전트가 직접 파일에 쓰기 (추천)**
에이전트의 파일 쓰기 도구로 `~/Documents/my-agent-test/AGENTS.md`에 초안 저장.

**(B) 학습자가 직접 복사·붙여넣기**
학습자가 본인 편집기로 AGENTS.md 열고 초안 붙여넣기.

→ 비개발자 친화 위해 (A) 우선 안내. (A)가 환경 제약(읽기 권한 등)으로 실패하면 (B)로 폴백.

### 1-7. 테스트

```
좋아요! 이제 AGENTS.md가 잘 동작하는지 확인해볼게요.
{{name}}님이 사용하시는 에이전트한테 다음과 같이 시켜보세요.

  👉 "지금 이 폴더의 AGENTS.md를 읽고 한 줄로 요약해줘. 그리고 빠진 부분이 있으면 알려줘."

답이 나오면 그대로 붙여넣어 주세요.
```

학습자가 결과를 붙여넣으면 → 검증으로.

## 옵션 ② — 기존 프로젝트

### 2-1. 프로젝트 위치 묻기

```
좋아요. 기존 프로젝트에 적용할 거예요.

어떤 프로젝트에 추가하시겠어요?
  - 폴더 경로를 알려주세요 (예: ~/code/my-blog)
  - 또는 폴더 이름만이라도 알려주세요. 같이 찾아볼게요.

그리고 짧게 한 줄로, 이 프로젝트가 무엇을 하는 곳인지 알려주세요.
```

### 2-2. draft 검증

학습자가 답한 *프로젝트 설명*과 `draft.overview`를 비교:

- 둘이 비슷하다 → "이론에서 적어주신 개요가 이 프로젝트 맥락이군요. 그대로 사용할게요."
- 다르다 → "이론에서 적어주신 개요는 다른 맥락 같아요. 이 프로젝트에 맞춰 다시 적을까요? 아니면 이전 개요를 손볼까요?"

### 2-3. 사전 점검 + 명령어 (OS 맞춤)

비용 안내: 없음 (옵션 ①과 동일).

{{os:darwin}}
```bash
# 프로젝트 폴더로 이동 (학습자가 답한 경로 사용)
cd ~/code/my-blog

# 기존 AGENTS.md가 이미 있는지 확인
ls -la AGENTS.md 2>/dev/null && echo "이미 있어요" || echo "없어요. 새로 만들 거예요"
```
{{/os}}

{{os:win32}}
```powershell
# 프로젝트 폴더로 이동
Set-Location "$HOME\code\my-blog"

# 기존 AGENTS.md가 이미 있는지 확인
if (Test-Path AGENTS.md) { Write-Host "이미 있어요" } else { Write-Host "없어요. 새로 만들 거예요" }
```
{{/os}}

→ 기존 파일이 *이미 있으면* "덮어쓰지 말고 추가/병합할까요?" 분기. 학습자가 OK 시 기존 내용 보존하며 보강.

### 2-4. 초안 작성 → 저장 → 테스트

옵션 ①의 1-5 ~ 1-7과 같은 흐름. *프로젝트 맥락*을 초안에 더 반영(예: "이 프로젝트는 OOO이므로…")하는 점만 다름.

## 검증 기준 (공통)

학습자가 테스트 결과를 붙여넣으면, 에이전트가 다음 점검을 수행합니다.

### 6개 표준 섹션 채움 여부

| 섹션 | 채워짐 판정 기준 |
|---|---|
| 프로젝트 개요 | 5단어 이상의 한 단락 |
| 톤과 스타일 | 1줄 이상 |
| 자주 쓰는 명령 | 1개 이상 (또는 명시적으로 "없음" 표기) |
| 주의사항 | 1줄 이상 |
| 도구·환경 | 1줄 이상 (선택 사항 — 비어도 OK) |
| 예시 | 1줄 이상 (선택 사항 — 비어도 OK) |

### 통과 판정

- **3개 이상의 *필수* 섹션이 채워지면 통과** (개요, 톤·스타일, 명령, 주의 중)
- 통과 시 `practice_status = "done"`, `status = "completed"`, `completed_at = 오늘 날짜` 갱신

### 통과 시 표시 (부족한 부분 명확히)

```

  ✅ 프로젝트 개요 — 채워졌어요
  ✅ 톤과 스타일 — 채워졌어요
  ✅ 자주 쓰는 명령 — 채워졌어요
  ✅ 주의사항 — 채워졌어요

  ⚠ 예시 — 비어 있어요 (선택 사항)

📌 *지금은 통과지만, 시간 날 때 추가하시면 더 든든해요:*

이번 실습은 ✅ 통과로 처리할게요. 다음 강의로 가실까요?
```

### 미통과 — 보강 필요

```
⚠ 아직 보강이 필요해요. 핵심 섹션이 부족해요.

  ✅ 프로젝트 개요 — 채워졌어요
  ❌ 톤과 스타일 — 비어 있어요 (필수)
  ❌ 자주 쓰는 명령 — 비어 있어요 (필수)
  ✅ 주의사항 — 채워졌어요

  • 톤과 스타일: 에이전트가 답할 때 어떤 분위기여야 하는지
    (예: "친근한 존댓말로", "코드는 80자 이내로")
```

## 트러블슈팅

### 자주 발생하는 에러

**"mkdir: cannot create directory" (Mac/Linux)**
원인: 이미 같은 이름의 폴더가 있거나, 권한 부족.
해결:
- 다른 이름 시도: `my-agent-test-2`
- 또는 권한 확인: `ls -ld ~/Documents`

**"New-Item: The path is not of a legal form" (Windows)**
원인: 경로에 특수문자/공백.
해결: 경로를 따옴표로 감싸기: `"$HOME\Documents\my agent test"`

**"AGENTS.md가 안 보여요"**
원인: 숨김 파일 설정, 또는 다른 폴더에 만들어짐.
해결:
- 현재 위치 확인: `pwd` (Mac) / `Get-Location` (Win)
- 파일 목록 확인: `ls -la` (Mac) / `Get-ChildItem -Force` (Win)

**"에이전트가 AGENTS.md를 못 읽어요"**
원인: 에이전트가 다른 폴더에서 실행 중. AGENTS.md가 있는 폴더에서 다시 시작 필요.
해결: 에이전트 종료 → 그 폴더로 `cd` → 다시 실행.

### 디버깅 루프 한계

3회 이상 재시도해도 풀리지 않거나 학습자가 "포기할게요" 입력 시:

```
음, 환경 문제일 수 있어요.

  (1) 다른 옵션으로 다시 시도 (옵션 ②로 전환)
  (2) 일단 ⚠ 미이행으로 표시하고 다음 강의로
  (3) 강의 작성자에게 에러 메시지 공유 (개선 자료)

어떻게 하시겠어요?
```
