# Lesson 1.1 — AGENTS.md가 뭐예요?

> 이 파일은 *한 청크*를 담고 있습니다. 출력 시 SKILL.md의 청크 헤더 규칙을 따르세요.

## Chunk 1

AGENTS.md는 *프로젝트 폴더 안에 두는 한 장의 안내서*예요. {{name}}님이 어떤 에이전트를 쓰시든(Claude Code · Codex · Cursor · Gemini · Antigravity) 그 폴더를 열 때마다 가장 먼저 이 파일을 읽고 "아, 이 프로젝트는 이런 분위기구나" 하고 톤을 잡습니다.

말하자면 *에이전트의 입사 첫날에 건네주는 회사 매뉴얼*과 비슷해요. 매번 같은 설명을 반복하지 않아도, 파일 하나만 잘 써두면 에이전트가 일관된 맥락에서 일해줍니다.
