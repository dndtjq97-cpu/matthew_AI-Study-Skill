# Lesson 9.4 — action 정의하기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

트리거 다음은 *액션*이에요. 트리거가 발사되면 *무엇을 할지* 정합니다.

좋은 액션의 특징:
- **빠름** — 5초 안에 끝나는 게 좋아요. 길어지면 작업 흐름이 끊김.
- **부작용 적음** — 다른 파일을 막 건드리지 않음.
- **실패해도 안전** — 실패 시 *원래 상태*로 돌아갈 수 있어야 함.

예를 들어 "파일 저장 시 → 자동 포맷팅"은 좋은 액션이에요. 빠르고, 그 파일만 다루고, 실패해도 원본이 있어요. 반면 "파일 저장 시 → 자동 배포"는 너무 위험해요.

🛠 **미션** — 3번 청크에서 고른 트리거에 대해 *액션 1가지*를 정해주세요. 한 줄이면 됩니다.

> 💾 적어주신 액션은 자동 보관됩니다. (`draft.action`)
