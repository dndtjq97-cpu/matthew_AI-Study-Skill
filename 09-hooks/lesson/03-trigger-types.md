# Lesson 9.3 — 트리거 이벤트의 종류

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

hook의 *트리거*는 보통 다음 카테고리예요.

1. **파일 이벤트** — 저장, 변경, 삭제, 생성
2. **버전 관리 이벤트** — 커밋 전·후, 푸시 전, 머지 후
3. **실행 이벤트** — 도구 시작·종료, 작업 완료
4. **시간 이벤트** — 매일 오전 9시, 매주 월요일
5. **외부 이벤트** — 메시지 도착, 메일 수신

처음 시작하시는 분께는 *(1) 파일 이벤트* 또는 *(2) 커밋 전*이 가장 와닿아요. 효과를 빨리 체감할 수 있어요.

🛠 **미션** — 본인 작업에 *어떤 트리거*가 가장 도움될 것 같나요? 1가지만 골라주세요.

> 💾 골라주신 트리거는 자동 보관됩니다. (`draft.trigger_event`)
