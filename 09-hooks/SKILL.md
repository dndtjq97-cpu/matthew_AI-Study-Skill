## 3. 이론 lesson 흐름

청크 8개.

### 9강에서 *왜* 한 청크씩 가는가
hook은 *자동으로 발사되는 코드*라 잘못 만들면 무한 루프나 의도치 않은 부작용을 만듭니다. 한 청크씩 *트리거 → 액션 → 안전 점검 → 다음*으로 가야 학습자가 *어떤 위험이 있을지* 의식하면서 만들 수 있습니다.

---

## 4. 가이드 실습 — 3개 옵션 (`practice/options/`)

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 진짜 hook을 만들어볼 시간이에요.

📝 트리거 이벤트: <draft.trigger_event>
📝 액션: <draft.action>
📝 엣지 케이스:
   - <draft.edge_cases[0]>
   - <draft.edge_cases[1]>

이걸 토대로 진짜 hook을 만들어볼게요.
```

### 4-1. 옵션 제시 (3개)

```
어떤 hook을 만들어보시겠어요?

  (1) 파일 저장 시 — 예: 저장하면 자동 포맷팅
  (2) 커밋 전 — 예: 커밋하기 전에 검사 실행
  (3) 다른 트리거 — {{name}}님이 직접 선택

번호로 답해주세요.
```

각 옵션 → `practice/options/<id>.md` 로드.

### 4-2. 가이드 실습 7단계
사전 점검(도구별 hook 지원) → 안전 패턴 안내 → 정의 → 등록 → 시연 → 검증.

### 4-3. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 트리거가 *실제로 발사*됨 | ✅ |
| 액션이 *예상대로* 동작 | ✅ |
| 엣지 케이스(예: 무한 루프 방지)가 *적어도 1개* 처리됨 | ✅ |

3개 중 2개 이상 ✅.
