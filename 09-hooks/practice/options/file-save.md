# Option: 파일 저장 시 hook

## 한 줄 요약
파일을 저장할 때마다 *자동으로 한 가지 작업*이 발사돼요.

## 흔한 액션 예시
- 자동 포맷팅 (코드 정리)
- 백업 한 부 생성
- 변경 사항을 NOTES.md에 한 줄 기록

## 사전 점검
- 도구의 *파일 저장 hook* 지원 여부 (부록)
- 액션이 5초 이내로 끝나는가?

## hook 정의 예시 (개념적)

```
on: file_save
when: 파일 확장자가 .py
action:
  - run: ruff format <파일 경로>
safe:
  - 액션 결과가 원본과 같으면 재저장 안 함 (무한 루프 방지)
```

## 등록 + 발사 테스트

도구별 등록 위치 (부록 참조). 등록 후:
1. 빈 파일 하나 만들고 저장
2. hook이 발사되는지 확인 (포맷팅이 적용되거나 로그가 찍힘)

## 안전 점검

- [ ] hook이 *자기 자신을 다시 트리거*하지 않는가?
- [ ] 액션이 *5초 안에* 끝나는가?
- [ ] 실패 시 원본 파일이 보존되는가?

## 자주 발생하는 에러
- 무한 저장 루프 → 즉시 hook 비활성화 + 변경 감지 추가
- 액션 권한 부족 → 도구별 hook 권한 설정

## 마무리 안내

방금 만든 패턴은 *다른 파일 이벤트*(생성·삭제·수정)에도 적용 가능해요.
