# Practice — 가이드 실습 (9강 hooks)

> `_shared/guided-practice-protocol.md`의 7단계 + 옵션 폴더 사용 (옵션 ≥3개).

## 0. 진입 직전 (draft 정리)

이론에서 적은 `trigger_event` / `action` / `edge_cases`를 정리해 보여줌.

## 1. 옵션 제시 (3개 → `practice/options/`)

```
어떤 hook을 만들어보시겠어요?

  (1) 파일 저장 시 — 예: 저장하면 자동 포맷팅
  (2) 커밋 전 — 예: 커밋 전 자동 검사
  (3) 다른 트리거 — {{name}}님이 직접 입력

번호로 답해주세요.
```

각 옵션 → `options/file-save.md` / `options/pre-commit.md` / `options/custom.md` 로드.

## 2. 공통 흐름

각 옵션 가이드는 다음 7단계를 담음:
1. 옵션 선택
2. 사전 점검 — 도구의 hook 기능 (부록), 권한
3. 비용 안내 — hook 자체 무료, 액션이 LLM 호출이면 호출당 비용
4. hook 정의 (트리거 + 액션) 작성
5. 등록 + 즉시 발사 테스트
6. 안전 점검 (무한 루프 방지)
7. 검증 + 마무리

## 3. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 트리거가 *실제 발사*됨 | ✅ |
| 액션이 *예상대로* 동작 | ✅ |
| 엣지 케이스 *적어도 1개* 처리 | ✅ |

3개 중 *2개 이상* 통과 시 ✅.

## 4. 트러블슈팅

- hook 안 발사 → 등록 위치 점검 (도구마다 다름)
- 무한 루프 → 즉시 hook 비활성화 + 변경 감지 추가
- 액션 권한 부족 → 학습자 OS에 맞는 권한 부여
