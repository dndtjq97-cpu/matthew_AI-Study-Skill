## 간단 호출 로그 템플릿 (수동)

```
| 날짜 | 작업 | 모델 | 입력 토큰 | 출력 토큰 | 비용 |
|---|---|---|---|---|---|
| 2026-05-02 | 글감 추천 | gemini-2.0-flash | 500 | 1200 | 무료 |
| 2026-05-02 | 회의록 요약 | claude-haiku-4-5 | 3000 | 800 | $0.005 |
```

이 표를 노션·구글 시트·md 파일 어디든 두고 *주간 리뷰* 시 합산.

## 토큰 절약 5가지 패턴

1. **컨텍스트 슬림화** — 매번 같은 자료 첨부 X
2. **캐싱** — 큰 컨텍스트 재사용 시 캐시 활용
3. **모델 다운그레이드** — 단순 작업엔 작은 모델
4. **출력 길이 제어** — "간결히" 또는 `max_tokens` 설정
5. **재시도 줄이기** — 한 번에 명확히 요청

## 자가 점검 (월 1회)

- [ ] 한 달 사용량이 *예상 범위* 내인가?
- [ ] *비정상적으로 비싼 호출*이 있었나?
- [ ] 모델 선택이 *작업 난이도*에 맞나?
- [ ] 매번 같은 첨부를 반복하고 있지 않나?
- [ ] 새 대화로 *분리할 수 있는* 흐름이 있나?
