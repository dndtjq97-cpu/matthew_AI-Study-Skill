# Lesson 12.1 — 토큰이 뭐예요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

**토큰**(token)은 LLM이 글을 *세는 단위*예요. 사람이 *글자*나 *단어*로 세는 것처럼, LLM은 *토큰*으로 셉니다.

대략 1 토큰 ≈ 영어 단어 1개 또는 한국어 글자 1.5~2개. 정확한 수치는 모델마다 달라요. 중요한 건 *모든 LLM이 토큰으로 비용을 매긴다*는 거예요.

이 강의는 두 부류 학습자 모두 해당해요:
- API 키 직접 사용 → 사용량 대시보드까지
- 도구만 사용(Claude Code/Cursor 등) → 토큰 절약 사고법까지

🛠 {{name}}님은 어느 쪽이세요?
  (1) API 키 직접 써요 (direct)
  (2) 도구만 써요 (indirect)
  (3) 잘 모르겠어요
