# Lesson 12.4 — 가격 대비 성능 좋은 모델 고르기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

같은 작업도 *어떤 모델로 호출*하느냐에 따라 비용이 *5~50배* 차이 나요.

대략적인 비교 (모델 가격은 자주 바뀜):
- **Haiku / Flash / Mini 같은 작은 모델** — 단순 작업, 빠르고 싸요
- **Sonnet / Pro 같은 중간 모델** — 일반 작업, 균형 좋음
- **Opus / Ultra 같은 큰 모델** — 복잡한 추론·창작

원칙: *작업의 어려움*에 *모델의 능력*을 맞추세요.

- 요약·번역·분류 → 작은 모델
- 글쓰기·코드 분석 → 중간 모델
- 복잡한 추론·연구 → 큰 모델

대부분의 일은 *중간 모델*로 충분해요. 큰 모델은 *진짜 어려운 작업*에만.
