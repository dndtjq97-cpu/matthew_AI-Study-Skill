# Lesson 12 — 비용 관리 (심화 트랙 5)

> 학습자가 끝나면 토큰·비용 메커니즘을 이해하고, *어떤 도구를 쓰든* 비용을 추적·절약하는 기본 방법을 익힌다.

⚠ **첫 청크에 안내**: API 키를 직접 안 쓰시는 분도 *토큰 개념*은 모든 도구 사용자에게 도움이 됩니다. 직접 키 사용 학습자는 *대시보드 점검*까지, 미사용 학습자는 *토큰 절약 사고*까지가 목표예요.

## 3. 이론 lesson 흐름
청크 8개. 첫 청크는 *토큰이 뭐예요? — 모든 LLM의 공통 단위*로 시작.

### 12강에서 *왜* 한 청크씩 가는가
비용은 *추상적*인데 청구서로만 체감되는 *지연된 피드백*이 있어요. 한 청크씩 *원리 → 본인 추정 → 절약 → 다음*으로 가야 학습자가 매 단계에서 *내 사용 패턴*과 연결할 수 있습니다.

## 4. 가이드 실습 — 옵션 2개 인라인 (학습자 유형별 분기)

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 본인 환경에 적용해볼 시간이에요.

📝 한 달 사용량 추정: <draft.current_monthly_estimate>
📝 자주/비싼 호출 후보:
   - <draft.top_3_calls[0]>
📝 적용할 절약 패턴:
   - <draft.optimization_ideas[0]>
```

### 4-1. 옵션 제시 (학습자 유형에 따라 자동 분기)

```
{{name}}님은 [direct/indirect] 학습자이시니까:

  (direct) (1) 사용량 대시보드 직접 점검 + 절약 1가지 적용 (추천)
           (2) 가상 사례로 연습
  (indirect) (1) 본인 도구의 토큰 사용 패턴 점검 + 슬림화 1가지
             (2) 가상 사례로 토큰 절약 사고 연습

번호로 답해주세요.
```

### 4-2. 옵션 ① — 본인 환경 적용
- direct: 가입한 제공자의 사용량 대시보드 URL 안내, 한 달 비용 확인, *비싼 호출 1개* 식별, 절약 패턴 1개 적용
- indirect: 본인 도구의 컨텍스트 패턴 점검, 슬림화 가능한 부분 1개 식별

### 4-3. 옵션 ② — 가상 사례
강의 제공 시나리오로 *동일한 사고*를 연습.

### 4-4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| 토큰 개념을 *한 줄로 설명* 가능 | ✅ |
| 본인 사용 패턴 (또는 가상)에서 *비싼 호출 1개 식별* | ✅ |
| 절약 패턴 1개를 *실제 적용*하거나 적용 계획 수립 | ✅ |

3개 중 2개 이상 ✅.
