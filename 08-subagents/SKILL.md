# Lesson 08 — 서브에이전트 (심화 트랙 1)

> 학습자가 끝나면 큰 작업 1개를 서브에이전트에 위임해 본인 컨텍스트를 보호하는 흐름을 *직접* 만들어본다.

심화 트랙의 첫 강의입니다. 기초에서 만든 환경 위에 *작업 위임*이라는 새 도구를 더합니다.

## 3. 이론 lesson 흐름

청크 8개.

### 8강에서 *왜* 한 청크씩 가는가
서브에이전트는 *위임 사고*를 익히는 강의입니다. "이건 위임할 만, 이건 직접" 구분 감각을 한 번에 다 못 익혀요. 한 청크씩 *예시 → 결정 → 다음*으로 가야 본인 작업에서 위임 후보를 알아보는 눈이 생깁니다.

---

## 4. 가이드 실습 — 옵션 2개 인라인

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 진짜 위임 작업을 만들어볼 시간이에요.

📝 전체 작업: <draft.parent_task>
📝 위임할 역할: <draft.subagent_role>
📝 입력: <draft.input_format>
📝 출력: <draft.output_format>

이걸 토대로 진짜 서브에이전트를 정의해볼게요.
```

### 4-1. 옵션 제시

```
어떤 작업으로 실습하시겠어요?

  (1) {{name}}님 본인 작업 (이론에서 적어주신 것)
  (2) 가상 사례 (예: "긴 문서 → 요약 + 액션아이템 추출")

번호로 답해주세요.
```

### 4-2. 옵션 ① — 본인 작업

`draft` 그대로 사용. 도구별 서브에이전트 호출 방식(부록 박스) 안내.

### 4-3. 옵션 ② — 가상 사례

강의 제공 시나리오 (예: 긴 회의록 → 서브에이전트가 요약 → 부모가 액션 추출).

### 4-4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| `subagent_role`이 *명확히 한 가지 책임* | ✅ |
| `input/output_format`이 *재현 가능한* 형태 | ✅ |
| 부모 → 서브에이전트 호출이 *실제로 작동* (1번 시연) | ✅ |

3개 중 2개 이상 ✅.
