# Lesson 8.6 — 도구별 호출 방식

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

서브에이전트 호출 방식은 *도구마다 살짝 달라요*. 다만 *개념*은 같아요.

> 💡 **도구별 호출 (참고용)**
>
> - Claude Code: `Task` 도구 또는 `Agent` 호출
> - Codex CLI: 대화 안에서 "이 부분만 다른 에이전트로" 지시
> - Cursor: 멀티 에이전트 모드 또는 서브 워크플로우
> - Gemini CLI: 도구 체이닝
> - Antigravity: 작업 위임 자동
>
> 정확한 명령은 도구마다 달라요. 가이드 실습에서 본인 도구에 맞게 안내드릴게요.

도구가 *서브에이전트를 직접 지원 안 함*이라면 *순차 실행*으로 폴백할 수 있어요. 한 대화에서 메인 작업 → 새 대화 또는 새 컨텍스트에서 서브 작업 → 결과를 다시 메인으로.

❓ 본인 도구에서 서브에이전트가 가능한지 *짐작*되세요? 잘 모르시면 "잘 모르겠어요"도 OK.
