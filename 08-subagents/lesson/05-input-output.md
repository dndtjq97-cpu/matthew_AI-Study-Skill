# Lesson 8.5 — 입력·출력 명확하게

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

위임에서 가장 자주 깨지는 게 *입력·출력 형식*이에요. 메인이 어떤 모양으로 *주고* 받을지를 미리 정해야 해요.

좋은 정의 예 — "회의록 요약 서브에이전트":
- **입력**: 마크다운 회의록 (참석자 + 안건 + 토론 내용)
- **출력**: 다음 형식의 마크다운
  ```
  # 액션아이템
  - [ ] 누가 / 무엇을 / 언제까지
  ```

이렇게 *형식*까지 정해두면 메인이 결과를 *그대로* 다음 단계에 넣을 수 있어요. 매번 *재해석*할 필요가 없어집니다.

🛠 **미션** — 4번 청크의 위임에 대해 *입력 형식*과 *출력 형식*을 한 줄씩 정해주세요.

> 💾 적어주신 형식은 자동 보관됩니다. (`draft.input_format` + `draft.output_format`)
