# Lesson 14.3 — 역할 분담 패턴 (라우터/계층/병렬)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

멀티 에이전트의 *3가지 기본 패턴*이에요.

**1. 라우터 (Router)**
```
[사용자] → [라우터] → A or B or C
```
입력을 보고 *적절한 에이전트로 전달*. 다양한 종류의 부탁을 받을 때 효과적.

**2. 계층 (Hierarchy)**
```
[메인] → [전문가1, 전문가2] → [메인이 통합]
```
메인이 부분 작업을 *서브에 위임*하고 결과를 통합. 큰 작업 분해에 효과적.

**3. 병렬 (Parallel)**
```
[입력] ⤵ [에이전트A]
       ⤵ [에이전트B]  → [통합]
       ⤵ [에이전트C]
```
같은 입력을 *여러 에이전트가 동시에* 처리. 다관점 분석·다원 검증에 효과적.
