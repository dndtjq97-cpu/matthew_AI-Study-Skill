# Lesson 14.6 — 도구별 멀티에이전트 지원

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

멀티 에이전트 지원은 도구마다 달라요.

> 💡 **도구별 지원 (참고)**
>
> - Claude Code: `Task` 도구로 서브에이전트 다중 호출 + 메인 통합
> - Codex CLI: 다중 에이전트 모드 또는 순차 호출
> - Cursor: 워크스페이스 + 멀티 에이전트 확장
> - Gemini CLI: 도구 체이닝 + 외부 워크플로우
> - Antigravity: Agent-first 환경에서 자동 위임
> - **n8n** (10강): *시각적*으로 멀티 에이전트 워크플로우 구축
>
> 정확한 명령은 도구별 문서 확인.

도구가 *직접 지원 안 함*이면 **n8n 워크플로우**로 만드는 게 가장 단순해요. 노드를 여러 개 두고 각각 다른 LLM 노드 또는 다른 모델로 설정.
