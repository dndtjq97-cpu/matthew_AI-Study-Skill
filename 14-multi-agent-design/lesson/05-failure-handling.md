# Lesson 14.5 — 실패 처리·합의

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

멀티 에이전트의 *가장 어려운 부분*은 *한 에이전트가 실패했을 때*예요.

처리 패턴:
- **재시도 (Retry)** — 실패 시 한 번 더. 가장 단순.
- **폴백 (Fallback)** — 실패 시 *다른 에이전트*가 대신.
- **합의 (Consensus)** — 여러 에이전트가 답하고 *다수결* 또는 *메인이 판단*.
- **롤백 (Rollback)** — 실패 시 *이전 상태*로 돌아감.

처음부터 *모든 패턴*을 적용할 필요 없어요. *재시도 + 메인 검증*만 있어도 대부분 OK. 자주 실패하는 부분만 *추가 보강*하세요.

🛠 **미션** — 본인 멀티 에이전트에서 *실패 가능성이 가장 큰 부분*과 *어떻게 처리할지*를 한 줄로 적어주세요.
