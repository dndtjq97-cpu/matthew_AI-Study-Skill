# Lesson 14.4 — 의사소통 프로토콜

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

에이전트끼리 *어떻게 소통*할지를 정해야 해요. 이걸 **프로토콜**이라고 해요.

기본 결정 사항:
1. **메시지 형식** — 텍스트? JSON? 마크다운?
2. **전달 방식** — 직접 전달? 중간 저장소를 통해?
3. **순서·동기화** — 누가 먼저? 동시에? 다 끝나야 다음?

가장 단순한 패턴 — **JSON 메시지 + 메인이 중계**:
```
[에이전트A] → JSON → [메인] → JSON → [에이전트B]
```

복잡한 시스템은 *메시지 큐* 같은 도구를 쓰지만, 처음에는 단순한 방식으로 시작하세요.

🛠 **미션** — 본인 멀티 에이전트가 *어떤 형식*으로 소통할지 한 줄로 적어주세요. (예: "JSON으로 메인이 중계", "마크다운으로 직접 전달")

> 💾 답변은 자동 보관됩니다. (`draft.communication_protocol`)
