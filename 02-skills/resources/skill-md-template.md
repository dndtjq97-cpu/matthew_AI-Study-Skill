# SKILL.md 표준 템플릿

> 이 파일은 *학습자가 만들 SKILL.md*의 형식 표준입니다. 가이드 실습에서 참고용으로 사용됩니다.

## 빈 템플릿

```markdown
---
name: <소문자-하이픈-이름>
description: <언제 사용하는지 + 어떤 표현이 트리거인지>
---

# <스킬 제목>

> 한 줄 학습 목표 또는 효용

## 진입 시 행동
- 학습자에게 짧게 인사
- 필요한 입력을 명시적으로 요청

## 핵심 단계
1. <단계 1>
2. <단계 2>
3. <단계 3>

## 결과 형식
- <결과의 형식·길이 등>

## 예시 (선택)
- ✅ 좋은 예
- ❌ 피할 예
```

## 작성 팁

- name: 영문 소문자·하이픈만 (예: `weekly-review-organizer`)
- description: "사용자가 ~할 때 사용. ~ 같은 표현으로 트리거" 형식이 좋음
- 본문은 *짧고 명확*하게. 200줄 이내.

## 좋은 description 예시

| ✅ 좋음 | ❌ 피할 표현 |
|---|---|
| "주간 회고를 정리할 때 사용. 일주일 일정을 잘된 점/아쉬운 점으로 분류" | "회고 도구" (너무 짧음) |
| "회의록 받아 액션아이템 추출. '회의록 정리해줘' 등 표현" | "정리해주는 거" (모호) |

## 도구 비종속 원칙

본문에 *특정 도구 이름*(Claude, Codex 등)을 직접 박지 마세요. *에이전트가*로 통칭하면 어떤 도구에서도 동작합니다.
