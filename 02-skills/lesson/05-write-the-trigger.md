# Lesson 2.5 — 트리거 표현 정하기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

트리거는 *에이전트가 이 스킬을 자동으로 떠올리게 하는 표현*이에요. {{name}}님이 평소 입에 잘 붙는 표현이 좋아요.

좋은 트리거 표현 예:
- "주간 회고 정리해줘"
- "오늘 회의록 요약해줘"
- "이번 주 글감 추천해줘"

이런 표현이 SKILL.md의 description 안에 들어가면, 에이전트가 비슷한 말을 들었을 때 *이 스킬을 떠올려* 호출하게 됩니다. 평소에 안 쓰는 표현보다 *입에 붙은 말*이 좋아요.

🛠 **미션** — {{name}}님이 자동화 작업을 부를 때 가장 자연스러운 트리거 표현 1~2개를 적어주세요.

> 💾 적어주신 표현은 자동으로 보관돼요.
