# Lesson 2.7 — name과 description 정하기

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

마지막은 frontmatter의 두 가지예요.

**name** — 소문자와 하이픈만 사용:
- ✅ `weekly-review-organizer`, `meeting-summarizer`, `blog-topic-recommender`
- ❌ `Weekly Review` (공백·대문자 X), `weekly_review` (밑줄 X)

**description** — *언제 사용하는지* 한 문장:
- ✅ "주간 회고를 정리할 때 사용. 일주일 일정·노트를 잘된 점/아쉬운 점으로 분류하고 다음 주 액션 제안."
- ❌ "회고 도구" (너무 짧음 → 트리거 어려움)

🛠 **미션** — {{name}}님 스킬의 name 1개와 description 1줄을 적어주세요.

> 💾 적어주신 두 항목은 자동으로 보관돼요.
