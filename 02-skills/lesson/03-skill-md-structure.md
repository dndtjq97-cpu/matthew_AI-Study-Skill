# Lesson 2.3 — SKILL.md 구조

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

SKILL.md는 *두 부분*으로 이루어져요.

```markdown
---
name: <소문자-하이픈-이름>
description: <언제 사용하는지 한 문장>
---

# 본문 (제목 + 흐름 설명)
...
```

위쪽 `---` 사이가 **frontmatter**예요. 에이전트가 *이 스킬을 언제 쓸지* 판단할 때 보는 부분이에요. 아래 본문은 *어떻게 작업할지*를 적어요. 아주 짧아도 OK이고, 길게 적어도 OK이에요. *명확함*이 길이보다 중요해요.

❓ frontmatter와 본문이 어떻게 다른지 감이 잡히세요? "이해됐어요" 또는 "어떤 부분이 헷갈려요"로 답해주세요.
