# Lesson 10.4 — n8n 설치 (Docker로 가장 쉽게)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

n8n 설치는 **Docker**로 가장 쉽게 해요. Docker가 *프로그램을 통째로 박스에 담아서 띄우는 도구*예요. 한 줄 명령으로 n8n이 떠요.

사전 점검:
- Docker Desktop 설치되어 있나요? (없으면 가이드 실습에서 함께 설치)
- 디스크 공간 약 1GB
- 설치 시간 5~10분

n8n 한 번 띄우면 *브라우저에서* 접속해서 사용해요 (보통 `http://localhost:5678`). 코드를 적을 일 없어요.

가이드 실습에서 학습자 OS에 맞는 정확한 명령어를 안내드릴게요. 지금은 *흐름만* 알아두시면 됩니다.
