# Lesson 10.3 — n8n이 뭐예요?

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

분해를 *시각적으로* 만들어주는 도구가 **n8n**(엔에잇엔)이에요. 작업 단계를 *노드*로 만들고, 노드 사이를 *선*으로 잇는 형태예요.

```
[트리거 노드] → [데이터 변환] → [LLM 호출] → [결과 저장]
```

이런 흐름을 *마우스로 끌어 연결*하면 끝이에요. 코드를 안 적어도 워크플로우가 만들어집니다. 비개발자에게 가장 친화적인 자동화 도구예요.

n8n은 **무료·오픈소스**고, 본인 컴퓨터에서 Docker로 띄울 수 있어요. 클라우드에 데이터 안 올려도 됩니다.
