# Lesson 10.6 — LLM API 노드 연결 (무료/유료 분기)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

n8n에 **LLM 노드**를 추가하면 워크플로우 안에서 LLM이 동작해요. 예를 들어 "받은 글 → LLM이 요약 → 결과 저장" 흐름이 가능합니다.

LLM 노드 연결은 두 가지 길:

✅ **무료 옵션**:
- Google AI Studio (Gemini) — 일일 한도까지 무료 (변동 가능)
- OpenRouter 일부 모델 — 무료 티어
- Anthropic 신규 가입 크레딧 — 있으면

💰 **유료 옵션**:
- 본인이 이미 가진 키 사용 (호출당 비용)

학습자 부담을 *최소화*하려면 무료 옵션부터. **꼭 LLM 노드를 안 넣어도 워크플로우는 동작**해요. 부담되시면 LLM 노드 *생략*하고 단순 워크플로우만 만들어도 ✅ 통과예요.
