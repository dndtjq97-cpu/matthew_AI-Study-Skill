# 부록 — 설정 + 보안 주의

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

원격 제어 설정 시 *반드시* 다음 안전장치:

1. **인증** — API 키 또는 OAuth 등 *강한 인증* 필수. 패스워드만 X.
2. **권한 범위 최소** — 필요한 작업만 가능하게. 전체 시스템 접근 X.
3. **로그** — 어디서 어떤 명령이 들어왔는지 *기록*. 의심 시 추적.
4. **타임아웃** — 일정 시간 후 자동 종료.
5. **신뢰된 IP만** — 가능하면 *본인 IP*로만 접근 제한.

설정 위치 (Claude Code):
- `~/.claude/settings.json` 또는 `claude config`

> 정확한 설정은 Claude Code 버전·문서 확인. 위는 *원칙*이고 명령은 도구마다 다름.
