# 부록 — Claude 원격 제어

> 10분 안에 원격 제어 개념 + 보안 주의 + 시연.

## 0. 시작하기 전에
공통 프로토콜 따름.

## 1. 진입 시 행동
1. 학습자 프로필 확인.
2. `progress["appendix-claude-remote-control"].status` 분기.
3. 첫 인사 + ⚠ 보안 사전 안내.
4. lesson 1~3개 진행.

## 2. lesson 흐름
- `lesson/01-when-useful.md` — 언제 원격 제어가 유용한가?
- `lesson/02-setup-and-security.md` — 설정 + 보안 주의
- `lesson/03-demo-or-skip.md` — 시연 (선택, 보안 부담 시 스킵)

## 3. 종료 시 행동
1. 진도 갱신
2. "다른 부록 더 보시겠어요?"

## 4. 강의 작성자 메타
- **트랙**: 부록 (Claude 전용)
- **선행**: 캡스톤(권장)
- **분량**: ~10분
- **외부 자료**: Claude Code (필수)
