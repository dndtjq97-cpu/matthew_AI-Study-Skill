# 부록 — VS Code 확장 설치

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

VS Code Claude 확장 설치 흐름.

사전 점검:
- VS Code 설치 여부 (없으면 code.visualstudio.com 에서)
- VS Code 버전이 *최신*에 가까운지 (오래된 버전은 호환성 문제 가능)

설치 (학습자 OS 공통):
1. VS Code 실행
2. 좌측 사이드바에서 **Extensions** 아이콘 (또는 `Cmd/Ctrl+Shift+X`)
3. 검색창에 "Claude" 입력
4. 공식 확장 선택 → **Install** 클릭
5. 재시작 안내 시 재시작

확장 활성화 후 *Claude 아이콘*이 사이드바에 나타나면 ✅ 설치 완료.

🛠 **미션** — 설치한 확장 버전을 한 줄로 적어주세요. (Extensions 패널에서 확인 가능)

> 💾 답변은 자동 보관됩니다. (`draft.installed_version`)
