## 진입 방식

부록은 **본 강의(15강)와 다른 자료**입니다. 다음 두 가지 경우에 들어와주세요.

1. **캡스톤(15강) 종료 후** — "이제 더 알고 싶다"는 마음이 들 때
2. **명시 호출** — 학습자가 "claude routines 안내해줘", "VS Code 확장 어떻게 깔지" 같이 직접 요청

학습자가 *Claude를 안 쓰면* 부록을 안 봐도 본 강의의 가치는 그대로 유지됩니다.

## 가벼운 패턴

- SKILL.md (간소)
