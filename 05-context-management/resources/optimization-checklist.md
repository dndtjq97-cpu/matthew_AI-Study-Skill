# 컨텍스트 최적화 체크리스트

## 슬림화 우선순위 (위에서 아래로 점검)

### 1. 매번 같은 자료 첨부?
- [ ] AGENTS.md → 한 번만 두고 매번 안 붙임 (도구가 자동으로 읽음)
- [ ] 긴 PDF → 요약본 1페이지로 대체
- [ ] 코드 전체 → *작업 중인 파일*만

### 2. 누적된 대화?
- [ ] 작업이 바뀌었으면 새 대화 시작
- [ ] 한 대화에서 *2시간 이상* 가지 않기
- [ ] 핵심 결정만 NOTES.md로 추출

### 3. 외부에 둘 수 있는 정보?
- [ ] 자주 쓰는 자료 → MCP로 *필요할 때만* 가져오기
- [ ] 결정 사항 → `decisions.md`에 한 줄씩
- [ ] 큰 데이터 → sqlite, Notion 등 외부

## 적용할 최적화 1가지 정하기

다음 중 *지금 가장 손이 가는 1가지*만 적용:

- 📌 **AGENTS.md 슬림화** — 길어진 부분을 NOTES.md로 옮김
- 📌 **새 대화 습관** — 작업 바뀌면 무조건 새 창
- 📌 **첨부 줄이기** — 매번 붙이던 PDF를 *요약본*으로 교체
- 📌 **외부 메모리 시작** — `NOTES.md` 파일 만들기 + 에이전트에게 "필요하면 읽어" 지시

## 효과 측정

적용 1주일 후 자가 평가:
- [ ] 답변 품질이 *그대로* 또는 *더 좋아짐*?
- [ ] 응답 *속도*가 개선?
- [ ] (API 사용자) 비용 *체감 감소*?

품질이 떨어졌다면 *줄인 자료 중 일부* 복원. 한 번에 다 줄이지 말고 *조금씩* 슬림화.
