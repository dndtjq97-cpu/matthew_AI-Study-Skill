# Practice — 가이드 실습 (5강 컨텍스트)

> `_shared/guided-practice-protocol.md`의 7단계를 따릅니다.

## 0. 진입 직전 (draft 정리)

이론에서 적은 `current_context_estimate` / `priority_items`를 정리해 보여줌.

## 1. 옵션 제시 (2개 인라인)

```
어디에 최적화 1가지를 적용해볼까요?

  (1) {{name}}님 본인 작업에 적용 (가장 추천)
  (2) 가상 시나리오로 연습

번호로 답해주세요.
```

## 2. 옵션 ① — 본인 작업 적용

### 2-1. 현재 사용 패턴 점검
학습자에게 짧게 묻기:
- 평소 가장 자주 쓰는 작업은?
- 그 작업에서 *컨텍스트에 항상 두는 것*은?
- *길어서 부담되는* 자료는?

### 2-2. 슬림화 기회 식별
함께 분석:
- 매번 첨부하는 자료 중 *요약본으로 대체 가능*한 것
- *외부 메모리*로 옮겨도 되는 것
- *새 대화 분리*로 리셋 가능한 흐름

### 2-3. 1가지 적용
**한 가지만** 골라 *실제로 적용*. 예:
- "AGENTS.md를 줄이고 NOTES.md로 분리"
- "긴 PDF를 1페이지 요약으로 대체"
- "작업 끝나면 새 대화창 시작 습관"

`draft.optimization_applied` 갱신.

## 3. 옵션 ② — 가상 시나리오 연습

강의 제공 시나리오 — "10페이지 문서를 매번 통째로 첨부하며 50번 대화" → *어떤 슬림화*가 가능한지 학습자와 함께 분석.

## 4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| `priority_items`에 3개 이상 분류 | ✅ |
| `optimization_applied`가 *실행 가능* | ✅ |
| 학습자가 *왜 이 최적화*를 골랐는지 한 줄로 설명 | ✅ |

3개 중 *2개 이상* 통과 시 ✅.

## 5. 트러블슈팅

- 슬림화 후 *답변 품질이 떨어짐* → 줄인 자료 중 *진짜 필수*가 빠진 것. 일부 복원.
- 외부 메모리를 안 읽음 → 에이전트한테 명시적으로 "필요하면 NOTES.md 읽어"라고 지시.
