# Lesson 05 — 컨텍스트 관리

> 학습자가 끝나면 컨텍스트 윈도우의 한계를 이해하고, 본인 작업에 *최적화 1가지*를 직접 적용한다.

이 스킬은 *대화형 강의*입니다. 한 청크씩 따라오며 학습자가 본인 작업의 컨텍스트 사용 패턴을 *직접 점검*하고 *어떤 부분을 슬림화할지* 결정합니다.

1. 학습자 프로필 확인.

4. 첫 인사.

6. 이론 마지막 → 가이드 실습 (옵션 2개 인라인).
7. 실습 종료 → 진도 갱신 + 다음 강의(6강) 안내.

## 3. 이론 lesson 흐름

청크 8개. `lesson/01-*.md` ~ `08-*.md`.

### 5강에서 *왜* 한 청크씩 가는가
컨텍스트 관리는 *추상적 개념*과 *실제 한계 체감*이 함께 가야 합니다. 한 청크씩 *개념 → 본인 사용량 점검 → 다음*으로 가야 학습자가 "아, 내 작업이 이래서 답이 이상했구나" 하고 깨닫고 본인 환경에 적용할 수 있습니다.

## 4. 가이드 실습 — 옵션 2개 인라인

### 4-0. 진입 시 draft 정리

```
🎉 이론 끝! 이제 본인 작업에 적용해볼 시간이에요.

📝 현재 사용량 추정: <draft.current_context_estimate>
📝 우선 항목들:
   - <draft.priority_items[0]>
   - <draft.priority_items[1]>

이 둘을 토대로 *최적화 1가지*를 적용해볼게요.
```

### 4-1. 옵션 제시

```
어디에 최적화를 적용해볼까요?

  (1) {{name}}님의 실제 작업에 적용
       (가장 추천 — 즉시 효과)
  (2) 가상 시나리오로 연습
       (실제 작업이 떠오르지 않으시면)

번호로 답해주세요.
```

### 4-2. 옵션 ① — 본인 작업에 적용

학습자에게 *현재 사용 중인 작업*을 짧게 듣고, *어떤 부분을 슬림화할지* 함께 결정. 적용 후 변화를 학습자가 체감하도록.

### 4-3. 옵션 ② — 가상 시나리오

강의가 제공하는 시나리오 (예: "10페이지짜리 문서 + 매번 전체 첨부")로 *어떤 슬림화가 가능한지* 함께 분석.

### 4-4. 검증 기준

| 항목 | 통과 기준 |
|---|---|
| `priority_items`에 3개 이상 항목 분류 | ✅ |
| `optimization_applied`가 *실제로 실행 가능한* 형태 | ✅ |
| 학습자가 *왜 이 최적화를 골랐는지* 한 줄로 설명 가능 | ✅ |

3개 중 2개 이상 ✅. 부족한 부분 명확히 명시.
