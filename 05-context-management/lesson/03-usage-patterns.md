# Lesson 5.3 — 컨텍스트 사용 패턴 보기 (3가지)

> 이 파일은 *한 청크*를 담고 있습니다.

## Chunk 1

컨텍스트 사용 패턴은 보통 *3가지*로 나뉘어요.

1. **상수형(Always)** — 매 응답마다 *항상* 필요한 정보 (AGENTS.md, 프로젝트 개요)
2. **요청형(On-Demand)** — *필요할 때만* 가져오는 정보 (특정 파일, 외부 데이터)
3. **누적형(Accumulating)** — 대화가 길어지면서 *점점 쌓이는* 정보 (이전 메시지 기록)

좋은 컨텍스트 관리는 1번을 *최소한*으로 두고, 2번을 *외부에서 가져오게* 하고, 3번을 *주기적으로 정리*하는 거예요. 다음 청크부터 이 3가지 각각을 어떻게 다룰지 봐드릴게요.
